# @bytechef/embedded-api

TypeScript client for the ByteChef Embedded public API (`/api/embedded/v1`), generated from the public OpenAPI
specifications. It uses the platform `fetch`, has no runtime dependencies and runs in the browser and in Node.js 18+.

> This package is `0.x`: the API it is generated from is not frozen yet, so minor versions may contain breaking
> changes.

## Install

```bash
npm install @bytechef/embedded-api
```

## Entry points

| Import | Covers |
|---|---|
| `@bytechef/embedded-api` | Integrations, integration instances, connections, connected users, automation workflows and templates |
| `@bytechef/embedded-api/execution` | Running component actions and listing tools for a connected user |
| `@bytechef/embedded-api/webhook` | App events and request triggers |

Each entry point is self-contained and has its own `Configuration`.

## Authentication

Operations come in two flavours:

- **Frontend operations** (no `externalUserId` parameter) run as the connected user. Authenticate them with the
  connected user's signed JWT.
- **Server-to-server operations** (with an `externalUserId` parameter) authenticate with your environment's API secret
  key. Call them from your backend only and never expose the key to a browser.

```ts
import {Configuration, IntegrationApi} from '@bytechef/embedded-api';

const integrationApi = new IntegrationApi(
    new Configuration({
        accessToken: connectedUserJwt,
        basePath: 'https://app.bytechef.io/api/embedded/v1',
    })
);

const integrations = await integrationApi.getFrontendIntegrations();
```

## Development

The sources under `src/` are generated by the Gradle `generateOpenAPITypeScriptFetch` tasks of the
`embedded-*-public-rest` modules. Do not edit them by hand; change the `openapi.yaml` and regenerate.

```bash
npm install
npm run build
```
