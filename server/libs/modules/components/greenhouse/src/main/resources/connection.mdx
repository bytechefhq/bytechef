## Connection Setup

### Create a Harvest API Key

1. Log in to [Greenhouse](https://app.greenhouse.io/) as a user with Developer permissions.
2. Click the *Configure* icon and select *Dev Center*.
3. Click *API Credential Management*.
4. Click *Create New API Key*.
5. Select *Harvest* as the API type, enter a description, and click *Manage permissions*.
6. Copy the API key.
7. Under *Candidates*, *Applications*, *Scorecards* and *Jobs*, enable the GET endpoints this component calls, then click *Save*.
8. In ByteChef, paste the key into the *Harvest API Key* field. ByteChef sends it as the Basic Auth username with an empty password.
