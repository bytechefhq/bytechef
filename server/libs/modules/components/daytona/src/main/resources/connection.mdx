## Connection Setup

1. Sign in to the [Daytona Dashboard](https://app.daytona.io/dashboard) and open the [Keys](https://app.daytona.io/dashboard/keys) page.
2. Click **Create Key**.
3. Enter a name for the key (e.g., **ByteChef**), set its expiration date, and select the `write:sandboxes` and `delete:sandboxes` permissions.
4. Click **Create** and copy the key.
5. In ByteChef, create a Daytona connection and paste the key into **API Key**.
6. Leave **Base URL** set to `https://app.daytona.io/api` unless you run a self-hosted Daytona deployment, in which case enter its API URL.
