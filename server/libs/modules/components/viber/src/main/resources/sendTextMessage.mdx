#### Things to know

- The receiver must have written to your bot before. Viber rejects messages to people who have not.
- To reply to someone, use the `user.id` from a Viber trigger as the Receiver ID. To learn more, click [here](/reference/components/viber_v1#how-to-find-the-receiver-id).
- Only plain text is supported. The text can be up to 7,000 characters and the sender name up to 28 characters.
- Tracking Data comes back with the person's next message, so you can use it to remember where a conversation is.
