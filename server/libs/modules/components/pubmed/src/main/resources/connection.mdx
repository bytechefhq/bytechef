## Connection Setup

The connection is optional. Without one, PubMed accepts up to 3 requests per second from your server. With an NCBI API key the limit is 10 requests per second.

### Create an NCBI API Key

1. Sign in to your [NCBI account](https://account.ncbi.nlm.nih.gov/) or create one.
2. Click your account name in the top right corner and select *Account settings*.
3. Scroll to *API Key Management* and click *Create an API Key*.
4. Copy the generated key and paste it into the *API Key* field of the connection.

### Tool and Email

*Tool* and *Email* are optional. NCBI asks applications that make many requests to identify themselves with the name of the application and a contact email address, so it can reach the developer before blocking traffic that causes problems. They are sent only when you fill them in.
