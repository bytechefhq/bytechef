#### Viber Bot Sender

Use the sender ID of the Viber bot that Infobip set up for your account. Infobip creates Viber bots under Viber's commercial terms, so ask your Infobip account manager if you do not have one yet.

The trigger output is the request Infobip forwards. Each item in `results` is one inbound event. The `sender` field holds the Viber user to reply to with the **Send Viber Bot Text Message** action.
