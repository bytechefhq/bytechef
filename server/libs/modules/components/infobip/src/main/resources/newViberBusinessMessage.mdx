#### Viber Sender

Use the Viber Business Messages sender that Infobip activated for your account.

The trigger output is the request Infobip forwards. Each item in `results` is one inbound message. The `sender` field holds the phone number of the Viber user. Use it as **To** in the **Send Viber Business Text Message** action to reply.
