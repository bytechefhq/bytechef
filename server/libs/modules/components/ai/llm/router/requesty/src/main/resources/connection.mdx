## Connection Setup

1. Login into your [Requesty console](https://app.requesty.ai/).
2. Open [API Keys](https://app.requesty.ai/api-keys).
3. Click on **Create API Key**.
4. Enter name of your API key and click on **Create**.
5. Copy your API key and paste it into the **Token** field in ByteChef.
6. Done.

Model IDs use the form `vendor/model`, for example `openai/gpt-4o-mini` or `anthropic/claude-sonnet-4-5`. The full list is available in the [Requesty model library](https://www.requesty.ai/models).
