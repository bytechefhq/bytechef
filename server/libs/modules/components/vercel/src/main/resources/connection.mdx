## Connection Setup

### Create a Vercel access token

1. Sign in to Vercel and open **Account Settings**, then **Tokens**.
2. Click **Create**, give the token a name and choose the scope (your personal account or a team) and an expiration.
3. Copy the token. Vercel shows it only once.
4. Paste it into the **Access Token** field of the ByteChef connection.

Good to know:
- A token scoped to a team can only act on that team. When you work with a team's projects, enter the Team ID (it starts with `team_`) in each action. Leave it empty for your personal account.
- Revoking the token in Vercel immediately stops every workflow that uses the connection.

Helpful links:
- Vercel REST API: https://vercel.com/docs/rest-api
- Vercel access tokens: https://vercel.com/account/tokens
