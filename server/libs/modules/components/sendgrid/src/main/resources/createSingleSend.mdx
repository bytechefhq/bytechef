#### Before you schedule

SendGrid creates the Single Send as a draft. Before you schedule it with **Schedule Single Send**, make sure that:

- The sender is verified. Use **List Senders** to check the `verified` flag.
- The Single Send has either an **Unsubscribe Group ID** or a **Custom Unsubscribe URL**.
- The API key has access to Marketing Campaigns. A key with **Full Access** permissions does.
