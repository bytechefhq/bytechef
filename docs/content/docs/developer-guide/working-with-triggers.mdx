## Download and Set Up ngrok

1. Download ngrok
    - Visit [ngrok's download page](https://ngrok.com/download) and download the appropriate version for your operating system
2. Start ngrok
    - Open a terminal and run the following command to start ngrok:
   ```bash
   ngrok http http://127.0.0.1:9555
   ```
    - Use the port your ByteChef server listens on: `9555` when you run it from the ByteChef codebase, `8080` when you run the `docker.bytechef.io/bytechef/bytechef` image with Docker or Docker Compose (`ngrok http http://127.0.0.1:8080`).
    - Copy the first address listed under "Forwarding". This will be used as your webhook URL.
    ![ngork example](/ngrok.png)

## Configure the webhook URL

Where the ngrok URL goes depends on how you run the server.

<Tabs items={['Docker', 'Docker Compose', 'ByteChef Codebase']}>
<Tab value="Docker">

If you run ByteChef with `docker run`, as in the **Docker (manual)** tab of [Local Docker](/platform/use-bytechef/self-hosted/installation/local-docker), pass the ngrok URL as the `BYTECHEF_WEBHOOK_URL` environment variable, replacing `(first address under Forwarding)` with the ngrok URL you copied:

```bash
docker run --name bytechef -it -p 8080:8080 \
    --env BYTECHEF_WEBHOOK_URL=(first address under Forwarding)/webhooks/{id} \
    ...
    docker.bytechef.io/bytechef/bytechef:latest
```

Keep the other options from your existing `docker run` command in place of `...`. An environment variable is read only when the container starts, so remove the old container (`docker rm -f bytechef`) and run the command again.

</Tab>
<Tab value="Docker Compose">

If you run ByteChef with the `docker-compose.yml` from [Local Docker](/platform/use-bytechef/self-hosted/installation/local-docker), add `BYTECHEF_WEBHOOK_URL` to the `environment` list of the `bytechef` service, replacing `(first address under Forwarding)` with the ngrok URL you copied:

```yaml
services:
  bytechef:
    environment:
      - BYTECHEF_WEBHOOK_URL=(first address under Forwarding)/webhooks/{id}
```

Then recreate the container so it picks up the new value:

```bash
docker compose -f docker-compose.yml up -d
```

</Tab>
<Tab value="ByteChef Codebase">

If you run the server from a clone of the ByteChef repository, the setting depends on how you start it.

<Tabs items={['IntelliJ IDEA', 'Without IntelliJ']}>
<Tab value="IntelliJ IDEA">

1. Open Bytechef Codebase:
    - Navigate to bytechef/server/apps/server-app/src/main/resources/config.
2. Create Local Configuration:
    - Create a file named `application-local.yml`.
    - Note: `application-local.yml` is optional, git-ignored, and corresponds to the `local` Spring profile. Ensure the `local` profile is activated on Spring Boot startup.
3. Configure Webhook URL:
    - Add the following configuration to `application-local.yml`, replacing `(first address under Forwarding)` with the copied ngrok URL:
   ```
   bytechef:
         webhook-url: (first address under Forwarding)/webhooks/{id}
     ```
4. Activate Local Profile:

    - Ensure that the `local` profile is added to active profiles in your IntelliJ configuration.
    ![intellij-scr](/intellij-scr.png)

5. Start the ByteChef application.

</Tab>
<Tab value="Without IntelliJ">

1. Navigate to the `BYTECHEF_HOME/server` directory create a file named `local.env`
2. Add the following configuration, replacing (first address under Forwarding) with the ngrok URL you copied:

   ```
    BYTECHEF_WEBHOOK_URL=(first address under Forwarding)/webhooks/{id}
    ```
3. Start the ByteChef application.

**Note:** Docker has to be restarted in order to update any changes made to `BYTECHEF_HOME/server/local.env` file.

</Tab>
