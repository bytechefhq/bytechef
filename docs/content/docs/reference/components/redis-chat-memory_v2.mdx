## Actions


### Add Messages
Name: addMessages

`Adds messages to a conversation, creating the conversation if it does not exist.`

#### Properties

|      Name       |      Label     |     Type     |     Description     | Required |
|:---------------:|:--------------:|:------------:|:-------------------:|:--------:|
| conversationId | Conversation ID | STRING | The unique identifier for the conversation. | true |
| userId | User ID | STRING | User id assigned to the conversation when it is created. | false |
| messages | Messages | ARRAY <details> <summary> Items </summary> [&#123;STRING\(role), STRING\(content)&#125;] </details> | The messages to add to the conversation. | true |

#### Example JSON Structure
```json
{
  "label" : "Add Messages",
  "name" : "addMessages",
  "parameters" : {
    "conversationId" : "",
    "userId" : "",
    "messages" : [ {
      "role" : "",
      "content" : ""
    } ]
  },
  "type" : "redisChatMemory/v2/addMessages"
}
```

#### Output



Type: OBJECT


#### Properties

|     Name     |     Type     |     Description     |
|:------------:|:------------:|:-------------------:|
| conversationId | STRING |  |
| messageCount | INTEGER |  |




#### Output Example
```json
{
  "conversationId" : "",
  "messageCount" : 1
}
```




### Get Messages
Name: getMessages

`Retrieves the messages of a conversation.`

#### Properties

|      Name       |      Label     |     Type     |     Description     | Required |
|:---------------:|:--------------:|:------------:|:-------------------:|:--------:|
| conversationId | Conversation ID | STRING | The unique identifier for the conversation. | true |
| includeCompactedHistory | Include compacted history | BOOLEAN <details> <summary> Options </summary> <span>true</span>, <span>false</span> </details> | When off, only the messages the agent currently sees are returned. | false |

#### Example JSON Structure
```json
{
  "label" : "Get Messages",
  "name" : "getMessages",
  "parameters" : {
    "conversationId" : "",
    "includeCompactedHistory" : false
  },
  "type" : "redisChatMemory/v2/getMessages"
}
```

#### Output



Type: OBJECT


#### Properties

|     Name     |     Type     |     Description     |
|:------------:|:------------:|:-------------------:|
| conversationId | STRING |  |
| messages | ARRAY <details> <summary> Items </summary> [&#123;STRING\(role), STRING\(content)&#125;] </details> |  |




#### Output Example
```json
{
  "conversationId" : "",
  "messages" : [ {
    "role" : "",
    "content" : ""
  } ]
}
```
