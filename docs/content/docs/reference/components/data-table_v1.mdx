### Delete Record(s)
Name: deleteRecords

`Delete records from a table by ID or by conditions`

#### Properties

|      Name       |      Label     |     Type     |     Description     | Required |
|:---------------:|:--------------:|:------------:|:-------------------:|:--------:|
| table | Table | STRING |  | true |
| deleteBy | Delete By | STRING <details> <summary> Options </summary> <span>IDS</span>, <span>CONDITIONS</span> </details> | Whether to delete the records with the given IDs or every record that matches the conditions. The editor asks for Record IDs until Conditions is chosen. In a workflow definition that leaves it out, conditions are used if only OR Conditions is given and Record IDs otherwise; it must be set when both are given. | false |
| ids | Record IDs | ARRAY <details> <summary> Items </summary> [INTEGER\($id)] </details> | IDs of records to delete; required unless Delete By is Conditions, and ignored when it is. | true |
| conditions | OR Conditions | ARRAY <details> <summary> Items </summary> [[&#123;STRING\(column), STRING\(operation), STRING\(value), STRING\(valueTo), [STRING]\(values)&#125;]] </details> | OR Condition array that contains AND Condition arrays; required when Delete By is Conditions. Every record that meets every condition of at least one AND Condition is deleted. Use Clear Table to delete every record. | true |

#### Example JSON Structure
```json
{
  "label" : "Delete Record(s)",
  "name" : "deleteRecords",
  "parameters" : {
    "table" : "",
    "deleteBy" : "",
    "ids" : [ 1 ],
    "conditions" : [ [ {
      "column" : "",
      "operation" : "",
      "value" : "",
      "valueTo" : "",
      "values" : [ "" ]
    } ] ]
  },
  "type" : "dataTable/v1/deleteRecords"
}
```

#### Output



Type: OBJECT


#### Properties

|     Name     |     Type     |     Description     |
|:------------:|:------------:|:-------------------:|
| deletedCount | INTEGER |  |
| deletedIds | ARRAY <details> <summary> Items </summary> [INTEGER] </details> |  |




#### Output Example
```json
{
  "deletedCount" : 1,
  "deletedIds" : [ 1 ]
}
```

### Find Records
Name: findRecords

`Find records in a table that match conditions`

#### Properties

|      Name       |      Label     |     Type     |     Description     | Required |
|:---------------:|:--------------:|:------------:|:-------------------:|:--------:|
| table | Table | STRING |  | true |
| conditions | OR Conditions | ARRAY <details> <summary> Items </summary> [[&#123;STRING\(column), STRING\(operation), STRING\(value), STRING\(valueTo), [STRING]\(values)&#125;]] </details> | OR Condition array that contains AND Condition arrays. A record is returned when it meets every condition of at least one AND Condition. Leave empty to return every record, up to Limit. | false |
| sortColumn | Sort Column | STRING <details> <summary> Depends On </summary> table </details> | Column to sort the records by. Records are sorted by id when not set. | false |
| sortDirection | Sort Direction | STRING <details> <summary> Options </summary> <span>ASC</span>, <span>DESC</span> </details> | Order of the Sort Column: Ascending or Descending. Has no effect when Sort Column is not set. | false |
| limit | Limit | INTEGER | Maximum number of records to return | false |
| offset | Offset | INTEGER | Number of records to skip | false |

#### Example JSON Structure
```json
{
  "label" : "Find Records",
  "name" : "findRecords",
  "parameters" : {
    "table" : "",
    "conditions" : [ [ {
      "column" : "",
      "operation" : "",
      "value" : "",
      "valueTo" : "",
      "values" : [ "" ]
    } ] ],
    "sortColumn" : "",
    "sortDirection" : "",
    "limit" : 1,
    "offset" : 1
  },
  "type" : "dataTable/v1/findRecords"
}
```

#### Output

The output for this action is dynamic and may vary depending on the input parameters. To determine the exact structure of the output, you need to execute the action.
