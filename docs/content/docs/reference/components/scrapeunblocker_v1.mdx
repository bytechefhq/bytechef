## Actions


### Get Page Source
Name: getPageSource

`Scrape a URL and return its fully rendered HTML, bypassing anti-bot protection such as Cloudflare, DataDome, PerimeterX and Akamai.`

#### Properties

|      Name       |      Label     |     Type     |     Description     | Required |
|:---------------:|:--------------:|:------------:|:-------------------:|:--------:|
| url | URL | STRING | The URL of the page to scrape. | true |
| proxy_country | Proxy Country | STRING | Two-letter country code for the proxy exit location (e.g. US, DE). | false |
| time_sleep | Wait Seconds | INTEGER | Number of seconds to wait after the page loads before the HTML is captured. | false |

#### Example JSON Structure
```json
{
  "label" : "Get Page Source",
  "name" : "getPageSource",
  "parameters" : {
    "url" : "",
    "proxy_country" : "",
    "time_sleep" : 1
  },
  "type" : "scrapeunblocker/v1/getPageSource"
}
```

#### Output



Type: STRING
