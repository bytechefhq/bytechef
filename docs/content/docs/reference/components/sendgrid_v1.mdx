## Connection Setup

1. Open your Dashboard: https://app.sendgrid.com .
2. Click on **Settings** and choose **API Keys**.
3. Click on **Create API Key**.
4. Enter **API Key Name**, choose **Full Access** permissions and click on **Create & View**.
5. Copy your generated API key and use it in Bytechef.

### Send Email
Name: sendEmail

`Sends an email.`

#### Properties

|      Name       |      Label     |     Type     |     Description     | Required |
|:---------------:|:--------------:|:------------:|:-------------------:|:--------:|
| from | From | STRING | Email address from which you want to send. | true |
| to | To | ARRAY <details> <summary> Items </summary> [STRING] </details> | Email addresses which you want to send to. | true |
| cc | CC | ARRAY <details> <summary> Items </summary> [STRING] </details> | Email address which receives a copy. | false |
| subject | Subject | STRING | Subject of your email. | true |
| text | Message Body | STRING | The message you want to send. | true |
| type | Message Type | STRING <details> <summary> Options </summary> <span>text/plain</span>, <span>text/html</span> </details> | Message type for your content. | true |
| attachments | Attachments | ARRAY <details> <summary> Items </summary> [FILE_ENTRY] </details> | A list of attachments you want to include with the email. | false |

#### Example JSON Structure
```json
{
  "label" : "Send Email",
  "name" : "sendEmail",
  "parameters" : {
    "from" : "",
    "to" : [ "" ],
    "cc" : [ "" ],
    "subject" : "",
    "text" : "",
    "type" : "",
    "attachments" : [ {
      "extension" : "",
      "mimeType" : "",
      "name" : "",
      "url" : ""
    } ]
  },
  "type" : "sendgrid/v1/sendEmail"
}
```

#### Output

This action does not produce any output.

### Create Single Send
Name: createSingleSend

`Creates a draft Marketing Campaigns Single Send. Use Schedule Single Send to send it.`

#### Properties

|      Name       |      Label     |     Type     |     Description     | Required |
|:---------------:|:--------------:|:------------:|:-------------------:|:--------:|
| name | Name | STRING | The name of the Single Send. | true |
| subject | Subject | STRING | The subject line of the email. | true |
| htmlContent | HTML Content | STRING | The HTML content of the email. | true |
| senderId | Sender ID | INTEGER | The ID of the verified sender the email is sent from. | true |
| listIds | List IDs | ARRAY <details> <summary> Items </summary> [STRING] </details> | The IDs of the contact lists the Single Send is sent to. | true |
| suppressionGroupId | Unsubscribe Group ID | INTEGER | The ID of the unsubscribe group recipients can opt out of. Scheduling requires either an unsubscribe group or a custom unsubscribe URL. | false |
| customUnsubscribeUrl | Custom Unsubscribe URL | STRING | The URL of your own unsubscribe page, used instead of an unsubscribe group. | false |

#### Example JSON Structure
```json
{
  "label" : "Create Single Send",
  "name" : "createSingleSend",
  "parameters" : {
    "name" : "",
    "subject" : "",
    "htmlContent" : "",
    "senderId" : 1,
    "listIds" : [ "" ],
    "suppressionGroupId" : 1,
    "customUnsubscribeUrl" : ""
  },
  "type" : "sendgrid/v1/createSingleSend"
}
```

#### Output



Type: OBJECT


#### Properties

|     Name     |     Type     |     Description     |
|:------------:|:------------:|:-------------------:|
| id | STRING | The ID of the Single Send. Pass it to Schedule Single Send. |
| name | STRING | The name of the Single Send. |
| status | STRING | The status of the Single Send: draft, scheduled or triggered. |
| send_at | STRING | The scheduled send time, when one is set. |
| send_to | OBJECT <details> <summary> Properties </summary> &#123;[STRING]\(list_ids)&#125; </details> |  |
| email_config | OBJECT <details> <summary> Properties </summary> &#123;STRING\(subject), STRING\(html_content), INTEGER\(sender_id), INTEGER\(suppression_group_id), STRING\(custom_unsubscribe_url)&#125; </details> |  |
| created_at | STRING | The time the Single Send was created. |
| updated_at | STRING | The time the Single Send was last updated. |




#### Output Example
```json
{
  "id" : "",
  "name" : "",
  "status" : "",
  "send_at" : "",
  "send_to" : {
    "list_ids" : [ "" ]
  },
  "email_config" : {
    "subject" : "",
    "html_content" : "",
    "sender_id" : 1,
    "suppression_group_id" : 1,
    "custom_unsubscribe_url" : ""
  },
  "created_at" : "",
  "updated_at" : ""
}
```

#### Before you schedule

SendGrid creates the Single Send as a draft. Before you schedule it with **Schedule Single Send**, make sure that:

- The sender is verified. Use **List Senders** to check the `verified` flag.
- The Single Send has either an **Unsubscribe Group ID** or a **Custom Unsubscribe URL**.
- The API key has access to Marketing Campaigns. A key with **Full Access** permissions does.

## Additional Instructions

#### How to find Template ID

- **Method 1: Via UI**

To find a Template ID, open your dashboard. In the left bar choose Email API -> Dynamic Templates. Expand the template you want to use and there you will find Template ID.

- **Method 2: Via API**

Use the `GET /templates?generations=dynamic` endpoint to retrieve a list of all dynamic templates and their IDs.
