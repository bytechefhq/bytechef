## Connection Setup

### Create an API Key

1. Sign in to your [SpecStream](https://specstream.ai/) workspace.
2. Open **Agents & API** (`https://specstream.ai/workspace/agents?tab=keys`).
3. Create an API key with the `finds:spend` scope and a spending limit.
4. Copy the API key and paste it into the **API Key** field.

## Actions


### Web Search
Name: webSearch

`Search the live web and return answers, structured rows, and ranked sources.`

#### Properties

|      Name       |      Label     |     Type     |     Description     | Required |
|:---------------:|:--------------:|:------------:|:-------------------:|:--------:|
| q | Query | STRING | The search query in plain words, in any language. Supports operators such as site:, filetype:, and quoted phrases. | true |
| speed | Speed | STRING <details> <summary> Options </summary> <span>default</span>, <span>fast</span> </details> | Search tier. Default returns answers, rows, and sources. Fast skips model reading and returns sources. | false |
| num | Number of Results | INTEGER | Maximum number of sources to return (1 to 100 for web search, up to 200 with images enabled). | false |
| page | Page | INTEGER | Page number (1 to 10) to continue the ranked result list. | false |
| passages | Include Passages | BOOLEAN <details> <summary> Options </summary> <span>true</span>, <span>false</span> </details> | When true, reads source pages and returns relevant text passages. | false |
| news | News | BOOLEAN <details> <summary> Options </summary> <span>true</span>, <span>false</span> </details> | When true, searches news results on the fast tier. | false |
| images | Images | BOOLEAN <details> <summary> Options </summary> <span>true</span>, <span>false</span> </details> | When true, returns image search results instead of web results. | false |
| country | Country | STRING | Two-letter country code to target results (for example US or DE). | false |
| language | Language | STRING | Two-letter language code for results (for example en or de). | false |
| safe | Safe Search | STRING <details> <summary> Options </summary> <span>off</span>, <span>moderate</span>, <span>strict</span> </details> | Safe search filtering level. | false |

#### Example JSON Structure
```json

    "page" : 1,
    "passages" : false,
    "news" : false,
    "images" : false,
```

### Extract Pages
Name: extract

`Extract the main text of up to 20 web pages or documents as Markdown, plain text, or HTML.`

#### Properties

|      Name       |      Label     |     Type     |     Description     | Required |
|:---------------:|:--------------:|:------------:|:-------------------:|:--------:|
| urls | URLs | ARRAY <details> <summary> Items </summary> [STRING] </details> | List of 1 to 20 HTTP or HTTPS URLs to read. | true |
| format | Format | STRING <details> <summary> Options </summary> <span>markdown</span>, <span>text</span>, <span>html</span> </details> | Output format for the extracted main content. | false |
| include | Include | ARRAY <details> <summary> Items </summary> [STRING] </details> | Additional fields to include on each extracted page. | false |

#### Example JSON Structure
```json
{
  "label" : "Extract Pages",
```
