## Actions


### Realtime Listen
Name: realtimeListen

`Transcribe audio in real-time using Deepgram's streaming speech-to-text API. Receives audio via WebSocket, forwards to Deepgram for transcription, and streams transcription results back.`

#### Properties

|      Name       |      Label     |     Type     |     Description     | Required |
|:---------------:|:--------------:|:------------:|:-------------------:|:--------:|
| model | Model | STRING <details> <summary> Options </summary> <span>nova-3</span>, <span>nova-2</span>, <span>nova-2-general</span>, <span>nova-2-meeting</span>, <span>nova-2-phonecall</span>, <span>enhanced</span>, <span>base</span> </details> | The AI model to use for transcription. | true |
| language | Language | STRING | The language code for transcription (e.g., 'en' for English). | false |
| encoding | Encoding | STRING <details> <summary> Options </summary> <span>linear16</span>, <span>flac</span>, <span>mulaw</span>, <span>alaw</span>, <span>opus</span>, <span>amr-nb</span>, <span>amr-wb</span>, <span>speex</span> </details> | The encoding of the audio data. | false |
| sampleRate | Sample Rate | STRING | The sample rate of the audio in Hz. | false |
| interimResults | Interim Results | BOOLEAN <details> <summary> Options </summary> <span>true</span>, <span>false</span> </details> | Whether to receive interim (non-final) transcription results. | false |
| punctuate | Punctuate | BOOLEAN <details> <summary> Options </summary> <span>true</span>, <span>false</span> </details> | Add punctuation and capitalization to the transcript. | false |
| smartFormat | Smart Format | BOOLEAN <details> <summary> Options </summary> <span>true</span>, <span>false</span> </details> | Apply formatting to improve transcript readability. | false |
| vadEvents | VAD Events | BOOLEAN <details> <summary> Options </summary> <span>true</span>, <span>false</span> </details> | Receive voice activity detection events. | false |

#### Example JSON Structure
```json
{
  "label" : "Realtime Listen",
  "name" : "realtimeListen",
  "parameters" : {
    "model" : "",
    "language" : "",
    "encoding" : "",
    "sampleRate" : "",
    "interimResults" : false,
    "punctuate" : false,
    "smartFormat" : false,
    "vadEvents" : false
  },
  "type" : "deepgram/v1/realtimeListen"
}
```

#### Output

This action does not produce any output.

### Voice Agent
Name: voiceAgent

`Start a real-time voice agent conversation using Deepgram's conversational AI API. Handles end-to-end voice interaction with integrated speech-to-text, LLM reasoning, and text-to-speech in a single WebSocket connection.`

#### Properties

|      Name       |      Label     |     Type     |     Description     | Required |
|:---------------:|:--------------:|:------------:|:-------------------:|:--------:|
| language | Language | STRING | The language for the voice agent conversation. | false |
| prompt | System Prompt | STRING | The system prompt that defines the agent's behavior and personality. | false |
| greeting | Greeting | STRING | The initial greeting the agent speaks when the conversation starts. | false |
| llmProvider | LLM Provider | STRING <details> <summary> Options </summary> <span>open_ai</span>, <span>anthropic</span>, <span>google</span>, <span>groq</span>, <span>aws_bedrock</span> </details> | The LLM provider for the agent's reasoning. | false |
| llmModel | LLM Model | STRING | The LLM model to use for reasoning. | false |
| ttsProvider | TTS Provider | STRING <details> <summary> Options </summary> <span>deepgram</span>, <span>eleven_labs</span>, <span>open_ai</span>, <span>cartesia</span>, <span>aws_polly</span> </details> | The text-to-speech provider for the agent's voice. | false |
| ttsModel | TTS Voice | STRING | The voice model for text-to-speech. | false |
| audioInputEncoding | Audio Input Encoding | STRING <details> <summary> Options </summary> <span>linear16</span>, <span>mulaw</span>, <span>alaw</span> </details> | The encoding of the input audio. | false |
| audioInputSampleRate | Audio Input Sample Rate | STRING | The sample rate of the input audio in Hz. | false |
| audioOutputEncoding | Audio Output Encoding | STRING <details> <summary> Options </summary> <span>linear16</span>, <span>mulaw</span>, <span>alaw</span> </details> | The encoding of the output audio. | false |
| audioOutputSampleRate | Audio Output Sample Rate | STRING | The sample rate of the output audio in Hz. | false |

#### Example JSON Structure
```json
{

    "ttsProvider" : "",
    "ttsModel" : "",
    "audioInputEncoding" : "",
    "audioInputSampleRate" : "",
    "audioOutputEncoding" : "",
    "audioOutputSampleRate" : ""
  },
  "type" : "deepgram/v1/voiceAgent"
}
```

#### Output

This action does not produce any output.
