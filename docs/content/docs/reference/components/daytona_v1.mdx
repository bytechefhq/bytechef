## Connection Setup

1. Sign in to the [Daytona Dashboard](https://app.daytona.io/dashboard) and open the [Keys](https://app.daytona.io/dashboard/keys) page.
2. Click **Create Key**.
3. Enter a name for the key (e.g., **ByteChef**), set its expiration date, and select the `write:sandboxes` and `delete:sandboxes` permissions.
4. Click **Create** and copy the key.
5. In ByteChef, create a Daytona connection and paste the key into **API Key**.
6. Leave **Base URL** set to `https://app.daytona.io/api` unless you run a self-hosted Daytona deployment, in which case enter its API URL.

## Actions


### Execute Code
Name: executeCode

`Generates and runs code in a secure, isolated Daytona sandbox and returns its output. Use this to execute AI-generated code (data analysis, calculations, scripts) safely and get the result back.`

#### Properties

|      Name       |      Label     |     Type     |     Description     | Required |
|:---------------:|:--------------:|:------------:|:-------------------:|:--------:|
| language | Language | STRING <details> <summary> Options </summary> <span>python</span>, <span>typescript</span>, <span>javascript</span>, <span>bash</span> </details> | The programming language of the code to execute. | true |
| code | Code | STRING | The source code to execute in the sandbox. | true |
| sandboxId | Sandbox ID | STRING | Run in an existing sandbox to preserve state across turns. Leave empty to create a fresh, ephemeral sandbox for this run. A reused sandbox is never deleted by this action. | false |
| keepSandbox | Keep Sandbox | BOOLEAN <details> <summary> Options </summary> <span>true</span>, <span>false</span> </details> | When creating a new sandbox, keep it alive after the run (instead of deleting it) so it can be reused via its returned Sandbox ID. Ignored when a Sandbox ID is supplied. | false |
| timeout | Timeout | INTEGER | Maximum time in seconds to wait for the code to finish executing. | false |

#### Example JSON Structure
```json
{
  "label" : "Execute Code",
  "name" : "executeCode",
  "parameters" : {
    "language" : "",
    "code" : "",
    "sandboxId" : "",
    "keepSandbox" : false,
    "timeout" : 1
  },
  "type" : "daytona/v1/executeCode"
}
```

#### Output



Type: OBJECT


#### Properties

|     Name     |     Type     |     Description     |
|:------------:|:------------:|:-------------------:|
| exitCode | INTEGER | The exit code of the executed code (0 indicates success). |
| stdout | STRING | The standard output produced by the code. |
| success | BOOLEAN <details> <summary> Options </summary> <span>true</span>, <span>false</span> </details> | Whether the code finished with a zero exit code. |
| sandboxId | STRING | The sandbox the code ran in (reuse it to preserve state). |
| charts | ARRAY <details> <summary> Items </summary> [] </details> | Chart artifacts (e.g. matplotlib) captured during execution, if any. |




#### Output Example
```json
{
  "exitCode" : 1,
  "stdout" : "",
  "success" : false,
  "sandboxId" : "",
  "charts" : [ ]
}
```

## Additional Instructions

#### Running code from an AI Agent

**Execute Code** is also available as a tool for the AI Agent. Add it under the agent's tools, and the agent can write code (Python, TypeScript, JavaScript or Bash), run it in an isolated Daytona sandbox, and use the output in its answer. This is useful for data analysis, calculations and scripts that the model should not try to compute in its head.

The tool returns `exitCode`, `stdout`, `success`, `sandboxId` and any `charts` the code produced (for example, matplotlib plots).

#### Sandbox lifecycle

By default, **Execute Code** creates a new sandbox, runs the code and deletes the sandbox when the run finishes, so nothing carries over between runs.

To keep files, installed packages and variables between runs:

1. Create a sandbox with **Create Sandbox**, or run **Execute Code** with **Keep Sandbox** enabled. Both return a `sandboxId`.
2. Pass that `sandboxId` to later **Execute Code** and **Upload File** calls. A sandbox passed in this way is never deleted by **Execute Code**.
3. Delete the sandbox with **Delete Sandbox** when you are done. Sandboxes you keep count against your Daytona usage until you delete them.
