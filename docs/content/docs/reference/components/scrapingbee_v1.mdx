## Actions


### Scrape URL
Name: scrapeUrl

`Scrape a web page through ScrapingBee's headless browsers and rotating proxies, and return its content as HTML, Markdown or plain text.`

#### Properties

|      Name       |      Label     |     Type     |     Description     | Required |
|:---------------:|:--------------:|:------------:|:-------------------:|:--------:|
| url | URL | STRING | The full URL of the page to scrape, including the protocol (e.g. https://example.com). | true |
| outputFormat | Output Format | STRING <details> <summary> Options </summary> <span>HTML</span>, <span>MARKDOWN</span>, <span>TEXT</span> </details> | Format of the returned page content. | true |
| render_js | Render JavaScript | BOOLEAN <details> <summary> Options </summary> <span>true</span>, <span>false</span> </details> | Render the page in a headless browser. Enabled by default by ScrapingBee and costs 5 credits per request; disable it for static pages to pay 1 credit. | false |
| proxyType | Proxy Type | STRING <details> <summary> Options </summary> <span>STANDARD</span>, <span>PREMIUM</span>, <span>STEALTH</span> </details> | Proxy pool to route the request through. Premium proxies cost 10 credits (25 with JavaScript rendering); stealth proxies cost 75 credits and require JavaScript rendering. | false |
| country_code | Country Code | STRING | ISO 3166-1 alpha-2 country code of the proxy exit location (e.g. us, de). Requires a premium or stealth proxy. | false |
| wait | Wait | INTEGER | Additional time in milliseconds to wait for the page to render. | false |
| wait_for | Wait For | STRING | CSS or XPath selector to wait for in the DOM before returning the response. | false |
| wait_browser | Wait Browser | STRING <details> <summary> Options </summary> <span>domcontentloaded</span>, <span>load</span>, <span>networkidle0</span>, <span>networkidle2</span> </details> | Browser condition to wait for before returning the response. | false |
| block_ads | Block Ads | BOOLEAN <details> <summary> Options </summary> <span>true</span>, <span>false</span> </details> | Block ads on the page. | false |
| block_resources | Block Resources | BOOLEAN <details> <summary> Options </summary> <span>true</span>, <span>false</span> </details> | Block images and CSS on the page. Enabled by default by ScrapingBee. | false |
| device | Device | STRING <details> <summary> Options </summary> <span>desktop</span>, <span>mobile</span> </details> | Device the request is sent from. | false |
| js_scenario | JavaScript Scenario | STRING | JSON instructions executed in the browser before the page is returned, e.g. &#123;"instructions": [&#123;"click": "#button"&#125;, &#123;"wait": 1000&#125;]&#125;. Requires JavaScript rendering. | false |
| cookies | Cookies | STRING | Cookies to send with the request, e.g. name_1=value_1;name_2=value_2. | false |
| session_id | Session ID | INTEGER | Route requests that share this ID through the same IP address for five minutes (0 to 10000000). | false |

#### Example JSON Structure
```json
{
  "label" : "Scrape URL",
  "name" : "scrapeUrl",
  "parameters" : {
    "url" : "",
    "outputFormat" : "",
    "render_js" : false,
    "proxyType" : "",
    "country_code" : "",
    "wait" : 1,
    "wait_for" : "",
    "wait_browser" : "",
    "block_ads" : false,
    "block_resources" : false,
    "device" : "",
    "js_scenario" : "",
    "cookies" : "",
    "session_id" : 1
  },
  "type" : "scrapingbee/v1/scrapeUrl"
}
```

#### Output



Type: STRING
