## Connection Setup

### Create a Vercel access token

1. Sign in to Vercel and open **Account Settings**, then **Tokens**.
2. Click **Create**, give the token a name and choose the scope (your personal account or a team) and an expiration.
3. Copy the token. Vercel shows it only once.
4. Paste it into the **Access Token** field of the ByteChef connection.

Good to know:
- A token scoped to a team can only act on that team. When you work with a team's projects, enter the Team ID (it starts with `team_`) in each action. Leave it empty for your personal account.
- Revoking the token in Vercel immediately stops every workflow that uses the connection.

Helpful links:
- Vercel REST API: https://vercel.com/docs/rest-api
- Vercel access tokens: https://vercel.com/account/tokens

### Create Deployment
Name: createDeployment

`Creates a deployment of a Git branch or commit in a Vercel project.`

#### Properties

|      Name       |      Label     |     Type     |     Description     | Required |
|:---------------:|:--------------:|:------------:|:-------------------:|:--------:|
| project | Project | STRING | The Vercel project to deploy. | true |
| org | Repository Owner | STRING | The GitHub organization or user that owns the repository. | true |
| repo | Repository | STRING | The name of the GitHub repository. | true |
| ref | Git Ref | STRING | The branch or tag to deploy. | true |
| sha | Commit SHA | STRING | The commit to deploy. Leave empty to deploy the latest commit of the ref. | false |

| teamId | Team ID | STRING | The team to act on behalf of. Leave empty to use the personal account. | false |

## Additional Instructions

#### Before you start

- The component works with Git-connected Vercel projects. Create Deployment builds a branch, tag or commit of a GitHub repository that is linked to the project.
- A deployment is a preview unless the Target is set to Production.
- Create Deployment returns as soon as Vercel queues the build. Use Get Deployment to follow the state until it is `READY`, `ERROR` or `CANCELED`.
