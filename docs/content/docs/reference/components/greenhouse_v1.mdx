## Connection Setup

### Create Harvest V3 (OAuth) Credentials

1. Log in to [Greenhouse](https://app.greenhouse.io/) as a user who can manage API credentials.
2. Open *API Credentials*.
3. Click *Create new API credentials*.
4. Select *Harvest V3 (OAuth)* and save the credential.
5. Configure the scopes of the credential. This component needs `harvest:candidates:list`, `harvest:applications:list`, `harvest:scorecards:list` and `harvest:jobs:list`.
6. Copy the *Client ID* and the *Client Secret*.
7. In ByteChef, paste them into the *Client ID* and *Client Secret* fields. Keep the default *Token URL*, `https://auth.greenhouse.io/token`.

ByteChef requests an access token with the OAuth 2.0 client credentials grant and sends it as a Bearer token to `https://harvest.greenhouse.io/v3`. Requests run as the integration service user that Greenhouse creates for the credentials.

### List Scorecards for Application

|      Name       |      Label     |     Type     |     Description     | Required |
|:---------------:|:--------------:|:------------:|:-------------------:|:--------:|
