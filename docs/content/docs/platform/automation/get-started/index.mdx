ByteChef Automation is the part of ByteChef where you build, deploy, and monitor workflows for your own team. A
workflow connects apps and services, runs on a trigger or on demand, and can include conditional logic, data
transformations, and AI agents. You build workflows in a visual editor, inside projects.

With ByteChef Automation you can:

- Connect applications and services through components and connections.
- Automate repetitive tasks and business processes.
- Add conditional logic, loops, and data transformations to a workflow.
- Add AI agents and AI actions to a workflow.
- Deploy a workflow to an environment and monitor its executions.

## Key Concepts

The terms used throughout this guide (project, workflow, component, trigger, action, connection, deployment) are
defined in the [Glossary](/platform/glossary).

## Create Your First Workflow

The general flow is the same for every workflow:

1. Open **Automation** and go to **Projects**.
2. Click **New Project** (or **Create Project** when the list is empty), enter a name, and click **Save**.
3. In the project, click **Create Workflow** (or **New Workflow**), enter a name, and click **Save**. The workflow
   editor opens.
4. Add a trigger and the actions the workflow needs, and configure their properties and connections.
5. Click **Test** to run the workflow, then click **Publish** and **Deploy** in the editor header.

## Best Practices

- **Start simple** - begin with a short workflow and add steps once it runs.
- **Test with different inputs** - run the workflow with the inputs you expect in production before you deploy it.
- **Use descriptive names** - give projects, workflows, and connections names that state their purpose.
- **Add descriptions** - describe what each workflow does so others can maintain it.
- **Reuse connections** - create a connection once and use it in every workflow that calls the same service.
