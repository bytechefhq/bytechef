---
title: Star Repository on GitHub
description: Connect a GitHub account to ByteChef with an OAuth app and run a workflow that stars a repository.
---

This guide connects a GitHub account to ByteChef and builds a workflow that stars a repository. You create a project, add a workflow, configure the GitHub **Star Repository** action with an OAuth 2.0 connection, and test it.

<Callout type="info">
  Step 3 asks for the **Client ID** and **Client Secret** of a GitHub OAuth app. If you do not have them yet, create the app first. See [Connect your GitHub account](#connect-your-github-account) at the end of this guide.
</Callout>

## 1. Create a project

A project is the container that holds your workflows.

<Steps>
<Step>

Open the **Projects** page and click **New Project** (or **Create Project** when the list is empty).

</Step>
<Step>

Enter a project name. Optionally add a description, choose a category, and add tags. Then click **Save**.

![The Create Project dialog with a name and description filled in](star-repository-on-github/create-project.png)

</Step>
</Steps>

## 2. Create a workflow

<Steps>
<Step>

Your new project's row opens with an empty **Workflows** tab. Click **Create Workflow**. Once a project has workflows, the same button reads **New Workflow**.

<Callout type="info">
  The chevron next to the button opens more options: **From Template**, **Import Workflow**, and **Import n8n Workflow**.
</Callout>

</Step>
<Step>

Enter a label for the workflow and an optional description, then click **Save**. ByteChef opens the new workflow in the editor.

![The Create Workflow dialog with a label and description filled in](star-repository-on-github/create-workflow.png)

</Step>
</Steps>

## 3. Add the GitHub component

<Steps>
<Step>

In the workflow editor, click the **+** button to add a component.

![A new workflow in the editor, showing the Manual trigger and the + button](star-repository-on-github/workflow-editor.png)

</Step>
<Step>

Search for and select the **GitHub** component, then choose the **Star Repository** action.

![The component picker filtered to GitHub](star-repository-on-github/component-picker.png)

With GitHub selected, its actions are listed on the right.

![The GitHub action list, including Star Repository](star-repository-on-github/star-repository-action.png)

</Step>
<Step>

Open the **Connection** tab and click **Create Connection**.

</Step>
<Step>

Enter a connection name, paste the Client ID and Client Secret of your GitHub OAuth app into **Client id** and **Client secret**, and click **Next**. Then click **Connect** and authorize ByteChef in the GitHub window that opens.

![The Create Connection dialog for GitHub, with Name, Client id and Client secret fields](star-repository-on-github/create-connection.png)

</Step>
<Step>

Back on the **Connection** tab, make sure the new connection is selected. If it is not, select it in the connection list.

![The GitHub node's Connection tab with a connection selected](star-repository-on-github/connection-tab.png)

</Step>
<Step>

Switch to the **Properties** tab and fill in the repository you want to star:

- **User/Organization** - the account that owns the repository, for example `bytechefhq`
- **Repository** - the repository name, for example `bytechef`

![The Star Repository action's Properties tab, filled in with bytechefhq and bytechef](star-repository-on-github/properties-tab.png)

</Step>
</Steps>

## 4. Test the workflow

<Steps>
<Step>

Click **Test** to run the workflow. ByteChef executes the **Star Repository** action against the repository you configured.

![The test run panel showing a DONE status and the executed Star Repository task](star-repository-on-github/test-run.png)

<Callout type="info">
  The **Output** tab reads *No output data*. This is expected: GitHub's star endpoint returns an empty
  `204 No Content` response. The green **DONE** badge and the task's green check show that the call succeeded.
</Callout>

</Step>
<Step>

Open the **Stars** tab on your GitHub profile. The repository you configured appears there.

</Step>
</Steps>

## Connect your GitHub account

The GitHub connection in step 3 authenticates through an OAuth app that you own. Create one as follows.

<Steps>
<Step>

Sign in to GitHub, click your profile icon in the top-right corner, and select **Settings**.

</Step>
<Step>

In the left sidebar, click **Developer settings**, then **OAuth Apps**, then **New OAuth App**.

</Step>
<Step>

Fill in the application details:

| Field | Value |
|---|---|
| **Application name** | A name for your app, for example `Test App` |
| **Homepage URL** | Your application's homepage, for example `https://www.bytechef.io/` |
| **Authorization callback URL** | `<public URL of your ByteChef instance>/callback`, for example `https://app.bytechef.io/callback`, or `http://localhost:8080/callback` for a local instance |

Then click **Register application**.

</Step>
<Step>

Click **Generate a new client secret**, then copy the **Client ID** and the **Client Secret**. You paste them into ByteChef in step 3.

<Callout type="warn">
  GitHub shows the client secret only once. Copy it before leaving the page.
</Callout>

</Step>
</Steps>
