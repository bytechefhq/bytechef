A **workflow chat** is a conversational interface to a workflow. A user types a message, the
message triggers the workflow, the workflow runs, and the reply appears in the chat thread,
streamed in real time when the workflow streams its output. Use workflow chats to give an
automation a chat front end without building a UI.

To chat with a workflow, open the **Chats** page in the Automation navigation. It lists every
chat-enabled workflow deployed in the selected environment, grouped by project. See
[Start a workflow chat](/platform/automation/build/hub/workflow-chats/using-chats).

<Callout type="warn" title="Coming soon">
  Starting workflow chats from the AI Hub composer is not available in the latest released version of ByteChef.
</Callout>

## When to use a workflow chat

A workflow chat fits any workflow that takes free-form text and returns a reply:

- Customer-support assistants that look up an order and draft a response.
- Internal question-answering bots that retrieve from a [knowledge base](/platform/automation/data/knowledge-base) and answer.
- Triage or intake flows where a person answers a few questions in conversation.
