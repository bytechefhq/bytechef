Basic Authentication is an authentication scheme built into HTTP. It authenticates each request with a username and a password.

## How it works

ByteChef joins the username and password with a colon, encodes the result with Base64, and sends it in the `Authorization` header of every HTTP request.

Example header:
`Authorization: Basic ZGVtbzpwQDU1dzByZA==`

## Set up a Basic Auth connection

{/* TODO screenshot: Create Connection dialog for a Basic Auth component showing the Username and Password fields with the Save button */}

1. Click **Connections** in the main sidebar.
2. Click **New Connection** and select a service that uses Basic Auth.
3. Enter a **Name** for the connection.
4. Enter the **Username**. Some services expect an email address or an API token here.
5. Enter the **Password**.
6. Click **Save**.

## Security

Base64 is an encoding, not encryption. Use Basic Authentication only over HTTPS so that credentials are not sent in plain text. ByteChef encrypts stored credentials at rest with AES-GCM.
