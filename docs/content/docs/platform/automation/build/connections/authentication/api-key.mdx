---

An API key is a secret identifier that a service issues to authenticate a user, developer, or program calling its API. Many third-party services use API keys for authentication.

## How it works

ByteChef sends the key with every request to the service's API, either in a header or as a query parameter. The component's connection definition decides which.

Example header:
`X-API-Key: abcdef12345`

Example query parameter:
`?api_key=abcdef12345`

## Find your API key

API keys are usually in the settings or developer dashboard of the service. Look for sections named:
- API Settings
- Developer Tools
- Security
- Integrations

## Set up an API key connection

{/* TODO screenshot: Create Connection dialog for an API-key component showing the Name field and the API Key (and optional secret) input fields with the Save button */}

1. Click **Connections** in the main sidebar.
2. Click **New Connection** and select a service that uses API keys.
3. Enter a **Name** for the connection.
4. Enter the API key. Some services also require additional fields, such as an API secret or an app ID.
5. Click **Save**.

## Security

Treat API keys like passwords. ByteChef encrypts stored API keys at rest with AES-GCM.
