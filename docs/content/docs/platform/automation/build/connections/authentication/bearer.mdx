Bearer Authentication (also called token authentication) is an HTTP authentication scheme that uses security tokens called bearer tokens. Any client that presents the token gets access.

## How it works

ByteChef sends the token in the `Authorization` header of every HTTP request, prefixed with `Bearer`.

Example header:
`Authorization: Bearer <your_token>`

## Find your bearer token

Bearer tokens are often personal access tokens (PATs) or tokens issued by an OAuth 2.0 flow. Look for them in the service's settings, in sections named:
- Developer Settings
- API Credentials
- Personal Access Tokens

## Set up a Bearer Token connection

{/* TODO screenshot: Create Connection dialog for a Bearer Token component showing the Token input field with the Save button */}

1. Click **Connections** in the main sidebar.
2. Click **New Connection** and select a service that uses Bearer Authentication.
3. Enter a **Name** for the connection.
4. Enter the **Token**.
5. Click **Save**.

## Security

Anyone who has a bearer token has the access it grants, so treat it like a password. ByteChef encrypts stored bearer tokens at rest with AES-GCM.
