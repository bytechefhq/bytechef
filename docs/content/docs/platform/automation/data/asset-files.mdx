**Asset Files** is the workspace's file library. Upload a file once and reuse it across workflows and AI conversations, and find the files that runs produce.

Asset files are scoped to a workspace and an environment. Use the environment selector in the left sidebar header to switch between Development, Staging, and Production.

## Upload files

Drag files onto the page's upload zone, or click the zone to select files. Uploaded files carry an **Upload** source badge, which distinguishes them from files produced by an AI Hub conversation or a workflow.

## Browse and organize

- **Filter by tag** - Select a tag in the left sidebar to narrow the list.
- **Edit tags** - Add or remove tags on the file's row.
- **Download** - Download the file from its row.
- **Rename** or **Delete** - Available on the file's row. Deleting asks for confirmation.

## Inspect a file

Click a file to open its **detail sheet**, also available at `/automation/asset-files/{fileId}`. The sheet shows the file name and an environment badge, previews the content, and has a **Download** button. You can edit and save text and code files in place.

The detail sheet uses the same viewer as the AI Hub resource panel. Preview support by type:

- **Markdown** renders as formatted text.
- **CSV** renders as a table (first 500 rows).
- **Charts** (AI-generated, `format=CHART`) render as interactive charts from their stored spec.
- **Interactive HTML** (AI-generated, `format=HTML`) renders with scripts enabled in an isolated frame. Plain HTML files render in a fully sandboxed frame.
- Other **text and code** files open in an editor with syntax highlighting.
- **Images** and **PDFs** render inline. PowerPoint and other binary files offer a download.

Text files have a **Preview / Split / Edit** toggle. **Split** shows the editor and the rendered preview side by side and updates the preview as you type.

## Version history

Each time a file's content changes (an in-place edit, a workflow action, or an AI agent update), the previous content is kept as a **version**. Click the clock icon in the detail sheet to open the history panel, browse versions, and **Restore** one. Restoring first saves the current content as a version, so you can undo a restore.

| Property | Default | Description |
|---|---|---|
| `bytechef.asset-file.max-versions-per-file` | `10` | Number of versions kept per file. A negative value keeps all versions. |

## Share a file

In a file's row menu, click **enable a public link** to create a URL with an unguessable token. Anyone with the URL can download the file (always as an attachment) without signing in. The same menu copies or disables the link. Disabling the link invalidates the URL immediately.

To turn off public links for the whole instance, set `bytechef.asset-file.sharing.public-link-enabled=false`. Existing links stop working immediately.

For programmatic integrations, the GraphQL query `assetFileSignedDownloadUrl` returns a **short-lived signed download URL** that expires after the platform's signed-URL TTL, without making the file public.

## Copilot on this page

A sparkle button in the page header opens the [AI Copilot](/platform/automation/build/ai-copilot) panel scoped to your files, in Ask or Build mode.

- **Ask mode** (read-only, the default) can list your files and read the text content of any file up to 1 MB.
- **Build mode** can additionally write a new text file (a report, a spec, CSV, JSON, markdown, or code), replace the content of an existing text file, store a base64-encoded binary file, or copy a file into another environment of the same workspace - for example, promoting a file from Development to Production.

Build mode can also fetch a file from a public URL and store it as an asset file. The server downloads the file, so the chat does not limit its size; the workspace's per-file size limit still applies. Restrictions:

- The URL must be a public `http` or `https` address. Private, loopback, and other internal addresses are refused.
- A URL that redirects is refused. The error names the redirect target so you can retry with the final URL.
- Fetched text content must be UTF-8.

The same file capabilities are also available in the [AI Hub](/platform/automation/build/hub) and on the [management MCP server](/platform/settings/mcp-server), through the `asset_file_agent` delegate.
