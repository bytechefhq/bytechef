---
title: Search
description: Run semantic queries against a knowledge base and inspect the matching chunks and relevance scores.
---

The **Search** tab queries a knowledge base the same way a workflow or agent does. Use it to
check that documents were ingested correctly and that a question retrieves the expected chunks
before you use the knowledge base in a workflow.

## Running a query

1. Open a knowledge base and switch to the **Search** tab.
2. Enter a natural-language query in **Search Query**. Search is **semantic**: it matches on
   meaning, so "how do I cancel" can find a chunk titled "Terminating a subscription" even though
   no words overlap.
3. Optionally, enter a JSON object in **Metadata Filters (JSON, optional)** to restrict which chunks can match.
4. Click **Search**. Results are ranked by relevance.

The result count appears above the results. Click **Clear Search** to reset.

## Reading the results

Each result card shows:

- The result number and the **source document** (the file name) the chunk came from.
- **Chunk** - The index of the matching chunk within the document.
- **Score** - The relevance from 0 to 100%; higher means a closer match.
- **Metadata** - The chunk's metadata, including the file name and metadata added during ingestion.

If a query returns no useful results, check that the relevant document is
**Ready** (see [Add documents](/platform/automation/data/knowledge-base/add-documents)), and check
whether the [chunk settings](/platform/automation/data/knowledge-base/create-a-knowledge-base#choosing-chunk-settings)
are splitting the content too finely or too coarsely.

## Metadata filters

The metadata filter narrows the candidates before ranking. It accepts a JSON object whose keys
are matched against each chunk's stored metadata, for example:

```json
{"file_name": "refund-policy.pdf"}
```

Only chunks whose metadata matches the filter can be returned. Workflows and agents use the
equivalent metadata and [tag filters](/platform/automation/data/knowledge-base/use-in-workflows#filtering-by-tag).
