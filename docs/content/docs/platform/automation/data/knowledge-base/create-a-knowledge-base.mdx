---
title: Create a Knowledge Base
description: Name a knowledge base and tune how its documents are split into chunks.
---

1. Click **Knowledge Base** in the Automation sidebar.
2. Click **New Knowledge Base** (or **Create Knowledge Base** when none exists yet).
3. Enter a **Name** and an optional **Description**.
4. Adjust the chunk settings if needed (see [Fields](#fields)).
5. Optionally, add files under **Upload Documents**.
6. Click **Create**.

## Fields

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| **Name** | Text | - | Required. The display name shown in the list and in workflow steps. |
| **Description** | Text | - | Optional description of the contents. |
| **Min Chunk Size (characters)** | Number | `1` | The smallest size of a chunk before it is merged with a neighbor. |
| **Max Chunk Size (tokens)** | Number | `1024` | The maximum size of a single chunk. |
| **Overlap Size (tokens)** | Number | `200` | How many tokens each chunk repeats from the previous chunk, so context is not lost at the boundary. |

After creation, **Edit** changes only the name and description. Chunk settings cannot be changed in the UI after creation.

You can upload documents in the create dialog or [add documents](/platform/automation/data/knowledge-base/add-documents) later.

## Choosing chunk settings

Chunking trades precision against context:

- **Smaller chunks** return more precise matches but may cut an idea in half.
- **Larger chunks** preserve more surrounding context but dilute relevance scores and cost
  more tokens when passed to a model.
- **Overlap** softens the boundaries so a sentence split across two chunks still appears in
  full in at least one of them.

The defaults (min `1` character, max `1024` tokens, overlap `200` tokens) suit prose documents such
as PDFs, Markdown, and help-center articles. Raise the max chunk size for long reference material
where whole sections should stay together. Lower it for fact-dense content such as FAQs.

<Callout type="warn" title="Chunk settings apply at ingestion">
  Chunk settings are applied when a document is processed. To chunk documents with different
  settings, create a new knowledge base and upload the documents there.
</Callout>

## Tags

Knowledge bases and their documents can be tagged. Tags filter the list in the left sidebar
and can narrow retrieval at query time; for example, an agent can be restricted to documents
tagged `policy`. See
[Use it in workflows and agents](/platform/automation/data/knowledge-base/use-in-workflows#filtering-by-tag).
