---
title: Add Documents
description: Upload files and follow them through the chunk-and-embed processing pipeline.
---

1. Open a knowledge base. The **Documents** tab is selected.
2. Click **Upload Document**.
3. Drag files onto the dialog or click to select them. You can select several files at once; they are listed under **Selected Files**.
4. Click **Upload**.

Each file is uploaded and then processed in the background. You can also upload files in the
[create dialog](/platform/automation/data/knowledge-base/create-a-knowledge-base).

## Supported file types

| Category | Extensions |
| --- | --- |
| Documents | `.pdf`, `.doc`, `.docx`, `.txt`, `.md`, `.html`, `.htm` |
| Presentations | `.ppt`, `.pptx` |
| Spreadsheets and data | `.csv`, `.xls`, `.xlsx` |

When OCR is configured (`BYTECHEF_AI_KNOWLEDGE_BASE_OCR_PROVIDER=MISTRAL`), scanned PDFs and
image-only pages are run through OCR before text extraction, so they become searchable. See
[Configuration](/platform/automation/data/knowledge-base#configuration).

## Storage limits

The total size of all knowledge base documents in a tenant is limited to **1 GB** by default.
An upload that would exceed the limit fails with an error until documents are deleted.
Self-hosted administrators can change or remove the limit with the
[`BYTECHEF_AI_KNOWLEDGE_BASE_MAX_SIZE_BYTES`](/platform/use-bytechef/self-hosted/configuration/environment-variables#ai-knowledge-base-configuration)
environment variable (`0` = unlimited).

## The processing lifecycle

Each document row in the **Documents** tab shows a status badge:

| Status | Meaning |
| --- | --- |
| **Uploaded** | The file has been received and is queued for processing. |
| **Processing** | Text is being extracted, chunked, and embedded. |
| **Ready** | The document is fully indexed and searchable. |
| **Error** | Processing failed. Delete the document and upload it again. |

A document is included in [search](/platform/automation/data/knowledge-base/search) results only when
it is **Ready**. Large files and PDFs that need OCR take longer to process.

## Review and edit chunks

Expand a document row to see its chunks. Each chunk has a menu with:

- **Edit** - Opens **Edit Chunk**, where you change the chunk's **Content**. The chunk is embedded again when you save.
- **Delete** - Removes the chunk from the knowledge base.

To delete several chunks, select them and click **Delete Selected** in the selection bar.

To delete a whole document, open its row menu and click **Delete**. Deleting and uploading a
document again runs the full processing pipeline.

## Tagging documents

Documents can be tagged individually. A workflow or agent can be restricted to documents with
given tags. Tag consistently when one knowledge base holds distinct content (for example
`policy`, `product`, `legal`) that you want to retrieve separately.

## Load documents from a workflow

To add content from another system, use the Knowledge Base component's **Load Data** action in a
workflow (see [Use it in workflows and agents](/platform/automation/data/knowledge-base/use-in-workflows#write-to-a-knowledge-base-from-a-workflow)).
