ByteChef keeps a working sample for each way you extend or embed the platform. Every repository builds or checks
locally, and its README walks through deploying it. Each table links the page that explains the feature.

## Code workflows

A whole project or integration defined in code - see [Code Workflows](/platform/automation/build/workflows/code-workflows).
Each sample has a local check that evaluates the file the way the server does and runs its tasks once.

| | Java | JavaScript | Python |
|---|---|---|---|
| **Automation project** | [bytechef-automation-sample-code-workflow-java](https://github.com/bytechefhq/bytechef-automation-sample-code-workflow-java) | [bytechef-automation-sample-code-workflow-javascript](https://github.com/bytechefhq/bytechef-automation-sample-code-workflow-javascript) | [bytechef-automation-sample-code-workflow-python](https://github.com/bytechefhq/bytechef-automation-sample-code-workflow-python) |
| **Embedded catalog code project** | [bytechef-embedded-automation-sample-code-workflow-java](https://github.com/bytechefhq/bytechef-embedded-automation-sample-code-workflow-java) | [bytechef-embedded-automation-sample-code-workflow-javascript](https://github.com/bytechefhq/bytechef-embedded-automation-sample-code-workflow-javascript) | [bytechef-embedded-automation-sample-code-workflow-python](https://github.com/bytechefhq/bytechef-embedded-automation-sample-code-workflow-python) |
| **Embedded code integration** | [bytechef-embedded-integration-sample-code-workflow-java](https://github.com/bytechefhq/bytechef-embedded-integration-sample-code-workflow-java) | [bytechef-embedded-integration-sample-code-workflow-javascript](https://github.com/bytechefhq/bytechef-embedded-integration-sample-code-workflow-javascript) | [bytechef-embedded-integration-sample-code-workflow-python](https://github.com/bytechefhq/bytechef-embedded-integration-sample-code-workflow-python) |

Each sample includes a workflow started by the Gmail **New Email** trigger, one that calls the Gmail **Search Email**
action, and `notifySlackOnNewEmail`, which posts each new email to Slack through a declared `slack` connection and
picks its channel from Slack's own `channel` input.

- **Automation project** - a project deployed to Automation → Projects; it also has a workflow that takes a `name` input
  and returns a greeting. See [Code Workflows](/platform/automation/build/workflows/code-workflows).
- **Embedded catalog code project** - a catalog project run by reference for your connected users; its
  `greetOnRequest` workflow has a Request trigger. See
  [Automation Code Workflows](/platform/embedded/build/automations/automation-code-workflows).
- **Embedded code integration** - an integration built on the Gmail component, so its Gmail calls need no declared
  connection. See [Code Integrations](/platform/embedded/build/code-integrations).

## Templates

Pre-built workflows and projects live in [bytechef-workflows](https://github.com/bytechefhq/bytechef-workflows) -
every workflow and project there is published as a template you can preview and import. See
[Templates](/platform/automation/build/workflows/templates).
