**ByteChef Cloud** is our managed, hosted deployment at [app.bytechef.io](https://app.bytechef.io/). Sign up and start building integrations and automations immediately — no servers, databases, or upgrades to manage.

## Why Cloud

Cloud is the fastest way to get a workspace running: sign up, connect the apps you use, and start building — updates, scaling, and infrastructure are handled for you.

- **Zero infrastructure** — no Docker, Kubernetes, or database to provision or patch.
- **Always up to date** — new features and connectors land automatically, no upgrade step.
- **Scales with you** — from a first workflow to production traffic, without capacity planning.

<Callout type="info">
  Need full control over data residency, networking, or custom infrastructure instead? See [Self-Hosted](/platform/use-bytechef/self-hosted).
</Callout>
