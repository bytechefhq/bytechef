**ByteChef Cloud** is the hosted ByteChef service at [app.bytechef.io](https://app.bytechef.io/). The ByteChef team runs the servers, database and upgrades; you sign up and build workflows and integrations in the browser.

## Cloud compared with self-hosted

| Concern | Cloud | Self-hosted |
|---|---|---|
| Infrastructure | Operated by ByteChef. No Docker, Kubernetes or database to provision. | You provision and operate the server, PostgreSQL and any broker or storage. |
| Upgrades | Applied by ByteChef; new features and components appear without an upgrade step. | You choose when to deploy a new image. |
| Data location and network | ByteChef's hosting. | Your infrastructure and network. |
| Configuration | Managed by ByteChef. | Every instance-wide option is yours to set. |

<Callout type="info">
  To control data residency, networking or infrastructure yourself, see [Self-Hosted](/platform/use-bytechef/self-hosted).
</Callout>
