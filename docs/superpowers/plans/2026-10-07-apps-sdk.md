# Apps — SDK (`@bytechef/app`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `@bytechef/app`, the framework-agnostic, server-only TypeScript client of the app-facing API
(`/api/app/v1`: connections, actions, tools, proxy, workflows), with `@bytechef/app/tanstack-start` and
`@bytechef/app/ai-sdk` subpath adapters, a TanStack Start test app, and CI that fails when the server contract and
the SDK's generated types drift.

**Architecture:** One npm workspace at `sdks/frontend/automation/app/` (`library/` = the package, `test-app/` = a
blank TanStack Start app that uses all three entry points), modelled on `sdks/frontend/automation/chat`. The core is
a thin typed `fetch` wrapper whose request/response types are generated from the landed
`automation-app-public-rest/openapi.yaml` with `openapi-typescript`; it has no runtime dependencies. The TanStack
adapter is built as middleware + plain handlers that every spike outcome shares, with the "ready-made server function"
layer shipped as a package export or as a template file depending on what Task 1 proves. The AI SDK adapter maps the
tool and workflow listings to `dynamicTool`s.

**Tech Stack:** TypeScript 5.7, Vite 8 library mode (`vite-plugin-dts`), vitest 4.1 with a mocked `fetch`,
`openapi-typescript` 7.13, `@tanstack/react-start` 1.168.x (optional peer), `ai` ^7 (optional peer), Verdaccio for
local publishing, Node 20.19+ for the core and 22.12+ for the workspace and adapters.

**Spec:** `docs/superpowers/specs/2026-10-06-apps-workflows-and-sdk-design.md`, section "Design — B. SDK" and
"Testing — B SDK". Background: `.agents/apps.md` (the server contract this SDK calls).

## Deviations from the spec, settled by the facts gathered before writing this plan

1. **`.validator`, not `.inputValidator`.** In `@tanstack/start-client-core` 1.170.34 (what `@tanstack/react-start`
   1.168.60 depends on) `inputValidator` is marked `@deprecated — Use validator instead`. The spec has it backwards.
   The adapter and its docs use `.validator(…)`. Task 10 corrects the spec.
2. **Library-shipped server functions are expected to compile; the spike proves it at runtime.** Start's Vite plugin
   (`start-plugin-core`, `crawlFrameworkPkgs` with `isFrameworkPkgByJson`) treats every dependency whose
   `peerDependencies` names `@tanstack/react-start` or `@tanstack/start-client-core` as a framework package: it goes
   on `resolve.noExternal` and through the Start compiler in both the client and the server build. The
   `@tanstack/react-start` peer entry is therefore load-bearing — dropping it would ship uncompiled server functions
   — and `package.test.ts` pins it (Task 2). Task 1 still proves at runtime, over SSR and over RPC from the browser,
   that a top-level server function and a factory-built one work when the package passes its handlers by reference.
   Task 6 always ships `bytechefMiddleware()` plus plain handlers and validators; the server-function layer ships as
   package exports when the spike confirms it, otherwise as a template file the app copies.
3. **`ai` requires `zod` as a non-optional peer.** Any app using the AI SDK already has it; `@bytechef/app` never
   imports zod and does not list it. The adapter uses `dynamicTool` + `jsonSchema`, whose `validate` is left unset
   (the server validates every call anyway).
4. **TypeScript stays on 5.x.** `openapi-typescript` 7.13 declares `peerDependencies.typescript: ^5.x`; the chat and
   embedded SDKs pin `5.7.3`, and this workspace does too (the TanStack scaffold's `^6` is replaced).
5. **A CI job is added.** Nothing under `sdks/` runs in CI today, so "`check:api` fails CI" needs a job: Task 10 adds
   an `sdk-app` job to `.github/workflows/build_pull_request.yml` and `build_push.yml`.
6. **Public type names have no `I` suffix.** The `I`/`Props` rule is the client's lint rule; a published SDK's types
   (`WorkflowRun`, `BytechefAppError`) are product surface and read as plain names, as `@bytechef/chat` partly does.
7. **`@tanstack/react-start` peer range is `^1.168.0`, not a pin.** The spec says "pinned to 1.168.x". An exact or
   `~` peer range would put every app that follows the Start scaffold's next minor into a peer conflict. The
   devDependency and the test app pin `1.168.60`, so the SDK is built and tested against exactly that release; the
   `^` range only states what apps may bring.
8. **Nine ready-made server functions, not seven.** `listTools` and `executeToolByName` are added: an app that renders
   its own tool picker needs both.
9. **Byte proxy bodies.** A `Uint8Array` body is sent BASE64 with `contentType` defaulting to
   `application/octet-stream` (the spec is silent). Over a TanStack server function only strings and JSON values
   cross the wire, so `proxyInput` admits no bytes, and `proxyHandler` returns the wire `body`/`bodyEncoding`
   unchanged so binary responses survive the trip.
10. **`INVALID_RESPONSE`.** A 2xx answer whose body is not JSON — the usual symptom of `BYTECHEF_URL` pointing at the
    web client instead of the API — becomes `BytechefAppError('INVALID_RESPONSE')` with the status, not a raw
    `SyntaxError`.
11. **Contract fix landed first.** `AppBinding.componentVersion` was described as null-able but not marked
    `nullable: true`; commit `149079d9fff` marks it, so the generated type is `componentVersion?: number | null`,
    which is what the server already sent.

## Global Constraints

- Package `@bytechef/app`, version `0.1.0`, `"type": "module"`, ESM only, `sideEffects: false`,
  `publishConfig.access: public`, `files: ["dist", "templates"]`, exports exactly `.`, `./tanstack-start`,
  `./ai-sdk` (each `{types, import}`), plus `./package.json`.
- The core entry has **no runtime dependencies** and uses only `fetch`, `AbortSignal`, `AbortController`,
  `TextEncoder`/`TextDecoder`, `atob`/`btoa`, `setTimeout`. `@tanstack/react-start` (`^1.168.0`) and `ai` (`^7.0.0`)
  are `peerDependencies` marked optional in `peerDependenciesMeta`; both are `external` in the Vite build. The
  `@tanstack/react-start` peer entry must stay (deviation 2).
- Environment variables `BYTECHEF_URL` and `BYTECHEF_APP_KEY`, read lazily on the first request through
  `globalThis.process?.env`; never under a `VITE_` prefix. Explicit `createBytechefClient({url, appKey, fetch,
  timeoutMs})` options win over the environment. Construction throws when `typeof window !== 'undefined'`.
- Every request sends `Authorization: Bearer <key>` and `Accept: application/json`; POSTs send
  `Content-Type: application/json`. Default client timeout 70 000 ms, covering the response body as well as the
  headers. No retries anywhere.
- `BytechefAppError extends Error` with `code: string`, `status?: number`, `runId?: string`, `message`. Server
  refusals carry the server's `code`/`message` and status. Client-side codes: `NETWORK_ERROR`, `TIMEOUT`, `ABORTED`
  (no status); `HTTP_ERROR` (error answer without a JSON `{code, message}` body; status set); `INVALID_RESPONSE`
  (2xx answer whose body is not JSON; status set); `APP_TOOL_NOT_FOUND` (from `executeByName`). A failed workflow run
  is data, never an exception.
- Types are generated from
  `server/ee/libs/automation/automation-app/automation-app-public-rest/openapi.yaml` into
  `library/src/generated/openapi.ts` with
  `openapi-typescript <spec> -o <out> --alphabetize --immutable --export-type --empty-objects-unknown`; the file
  is committed; `check:api` runs the same with `--check` and fails on drift.
- Tool helper semantics: `executeByName` resolves a flat name through the cached `GET /tools` listing (TTL 60 000
  ms), re-fetches once on a miss, and never parses names. A tool whose `parameters` is not a JSON object is listed
  with `{additionalProperties: true, type: 'object'}`.
- `workflows.execute(key, input, {wait, signal, waitSeconds})`: `wait: true` polls `getRun` with delays
  1 000, 2 000, 3 000, 4 000, 5 000, 5 000… ms until `COMPLETED`/`FAILED`/`CANCELLED`, stopping at
  `APPROVAL_REQUIRED`; `wait: 'approval'` keeps polling through `APPROVAL_REQUIRED`; `signal` aborts the wait with
  `BytechefAppError('ABORTED')` carrying the run's `runId`.
- The TanStack adapter exports `bytechefMiddleware()` built with `createMiddleware({type: 'function'})`; one
  middleware — hence one client and one tool cache — serves all ready-made server functions of one
  `createBytechefServerFns` call, and one module-level middleware serves the module-level exports. Handlers are plain
  functions `({data, context}) => …`; input validators are plain functions `(input: unknown) => T` that throw
  `TypeError` on bad shapes.
- The AI SDK adapter builds every tool with `dynamicTool({description, inputSchema: jsonSchema(schema), execute})`;
  component tools are named by their flat name, workflows by `toFlatKey(workflowKey)` (upper-case, every run of
  non-alphanumerics → `_`); `include` filters by flat name, binding key or workflow key; `execute` forwards the AI
  SDK's `abortSignal`; a `BytechefAppError` other than `ABORTED` is returned to the model as text, while `ABORTED`
  and every other error are thrown.
- Node: library `engines.node` `>=20.19.0` (the spec's Node 20+; the peers enforce their own 22.12); workspace root
  and test app `>=22.12.0`. `typescript` `5.7.3`, `vitest` `4.1.7`, `vite` `^8.0.14`, `vite-plugin-dts` `5.0.1`,
  `prettier` `3.8.3` with the chat workspace's `.prettierrc` (4 spaces, single quotes, 120 cols).
- Commit subjects: `- sdk - <description>` for anything under `sdks/`, `- docs - <description>` for docs,
  `- <description>` for CI. No `Co-Authored-By` or "Generated with" trailers. Never amend; commit by path, never
  `git add -A`. Run `npx prettier --write` on touched files and `npm run lint` before each commit.
- npm/npx install, build and test commands run in the foreground with `timeout: 600000`, output redirected to a file
  and `$?` checked on its own line. The only background process allowed is a `vite preview` server, started with the
  Bash tool's `run_in_background: true` (never `&`) and stopped (`pkill -f 'vite preview --port 3999'`) before the
  task ends. Wait for it with `curl --retry 30 --retry-delay 1 --retry-connrefused`, never `sleep`. A 600 s
  no-progress watchdog kills an agent and discards uncommitted work: commit after each task, write reports
  incrementally.
- No rationale `//` comments in committed code; JSDoc that states a contract is fine. Never publish to npmjs: only
  `publish:local` to Verdaccio is allowed, and only when a task says so.

## Review Focus

Inputs the spec implies but no task's tests would otherwise exercise; each now has a test in the task named.

1. **A non-JSON body** — an HTML 502 from a proxy in front of ByteChef, an empty 401, or a 200 HTML page because
   `BYTECHEF_URL` points at the web client — must become `BytechefAppError` with `status` set (`HTTP_ERROR` /
   `INVALID_RESPONSE`), not a JSON parse crash — Task 3 (`request.test.ts`).
2. **`BYTECHEF_URL` with a trailing slash or a path** (`https://x/`, `https://x/bytechef`) must produce
   `https://x/api/app/v1/…` and `https://x/bytechef/api/app/v1/…`, never `//api` — Task 3 (`config.test.ts`).
3. **`executeByName` on a tool the admin just removed** must throw `APP_TOOL_NOT_FOUND` after exactly one re-fetch,
   not loop — Task 4 (`tools.test.ts`).
4. **A proxied upstream 404** is returned as a `ProxyResult` with `status: 404`, not thrown; a ByteChef 404
   (`APP_CONNECTION_NOT_FOUND`) is thrown — Task 4 (`proxy.test.ts`, both cases side by side).
5. **An abort while waiting for a run** (the request is aborted, or `generateText` is cancelled while a workflow tool
   waits for an approval) stops polling with `ABORTED`, and the error carries `runId` so the app can resume — Task 5
   (`workflows.test.ts`, aborting inside the first poll delay) and Task 7 (`tools.test.ts`, signal forwarded and
   `ABORTED` rethrown).

  ```js
  import {createMiddleware, createServerFn} from '@tanstack/react-start';

  export const spikeMiddleware = createMiddleware({type: 'function'}).server(({next}) =>
      next({context: {spike: 'CANARY_MIDDLEWARE_SERVER'}})
  );

  export function handlerA({context}) {
      return {answer: `CANARY_HANDLER_A:${context.spike}`};
  }

  export function handlerB({context}) {
      return {answer: `CANARY_HANDLER_B:${context.spike}`};
  }

  export function handlerC({context}) {
      return {answer: `CANARY_HANDLER_C:${context.spike}`};
  }

  export function validateInput(input) {
      if (typeof input !== 'object' || input === null || typeof input.name !== 'string') {
          throw new TypeError('name must be a string');
      }

      return {name: input.name};
  }

  export const pingFromPackage = createServerFn({method: 'POST'})
      .middleware([spikeMiddleware])
      .validator(validateInput)
      .handler(handlerA);

  export function createSpikeServerFns() {
      return {
          ping: createServerFn({method: 'POST'}).middleware([spikeMiddleware]).validator(validateInput).handler(handlerB),
      };
  }
  ```

- [ ] **Step 3: Write the route** `$S/spike/src/routes/index.tsx`. The loader calls all three variants during SSR;
  the button calls them again from the browser over RPC:

  ```tsx
  import {createFileRoute} from '@tanstack/react-router';
  import {createServerFn} from '@tanstack/react-start';
  import {useState} from 'react';
  import {createSpikeServerFns, handlerC, pingFromPackage, spikeMiddleware, validateInput} from 'spike-lib';

  const fromFactory = createSpikeServerFns();
  const pingFromApp = createServerFn({method: 'POST'}).middleware([spikeMiddleware]).validator(validateInput).handler(handlerC);

  const variants = [
      ['A', pingFromPackage],
      ['B', fromFactory.ping],
      ['C', pingFromApp],
  ] as const;

  async function runAll(): Promise<string[]> {
      const results: string[] = [];

      for (const [label, serverFn] of variants) {
          try {
              const result = (await serverFn({data: {name: label}})) as {answer: string};

              results.push(`${label}=${result.answer}`);
          } catch (error) {
              results.push(`${label}=ERROR ${(error as Error).message}`);
          }
      }

      return results;
  }

  export const Route = createFileRoute('/')({
      component: Home,
      loader: () => runAll(),
  });

  function Home() {
      const ssrAnswers = Route.useLoaderData();
      const [browserAnswers, setBrowserAnswers] = useState<string[]>([]);

      return (
          <main>
              <pre id="ssr">{ssrAnswers.join('\n')}</pre>
              <button id="run" onClick={() => runAll().then(setBrowserAnswers)} type="button">
                  run
              </button>
              <pre id="browser">{browserAnswers.join('\n')}</pre>
          </main>
      );
  }
  ```

  ```ts
  import {vi} from 'vitest';

  export interface MockResponseSpec {
      body?: unknown;
      headers?: Record<string, string>;
      status?: number;
      text?: string;
  }

  export function jsonResponse(spec: MockResponseSpec = {}): Response {
      const status = spec.status ?? 200;
      const headers = new Headers({'content-type': 'application/json', ...spec.headers});

      if (spec.text !== undefined) {
          return new Response(spec.text, {headers, status});
      }

      return new Response(spec.body === undefined ? null : JSON.stringify(spec.body), {headers, status});
  }

  export function mockFetch(...responses: Array<Response | Error | ((input: RequestInfo | URL, init?: RequestInit) => Response | Promise<Response>)>) {
      const calls: Array<{input: RequestInfo | URL; init?: RequestInit}> = [];
      let index = 0;

      const fetchMock = vi.fn(async (input: RequestInfo | URL, init?: RequestInit) => {
          calls.push({init, input});

          const next = responses[Math.min(index, responses.length - 1)];

          index += 1;

          if (next instanceof Error) {
              throw next;
          }

          if (typeof next === 'function') {
              return next(input, init);
          }

          return next!.clone();
      });

      return {calls, fetch: fetchMock as unknown as typeof fetch};
  }

  export function lastRequest(calls: Array<{input: RequestInfo | URL; init?: RequestInit}>) {
      const last = calls[calls.length - 1]!;
      const url = typeof last.input === 'string' ? last.input : last.input instanceof URL ? last.input.href : last.input.url;
      const headers = new Headers(last.init?.headers);

      return {body: last.init?.body, headers, method: last.init?.method ?? 'GET', url};
  }
  ```

  ```ts
  import {joinUrl, type ResolvedConfig} from './config';
  import {BytechefAppError} from './errors';

  export const API_PREFIX = '/api/app/v1';

  export interface RequestOptions {
      body?: unknown;
      method: 'GET' | 'POST';
      path: string;
      signal?: AbortSignal;
  }

  export interface RequestResult<T> {
      data: T;
      status: number;
  }

  export interface Requester {
      <T>(options: RequestOptions): Promise<RequestResult<T>>;
  }

  interface ErrorBody {
      code?: unknown;
      message?: unknown;
  }

  function abortError(signal: AbortSignal): BytechefAppError {
      return signal.reason instanceof BytechefAppError
          ? signal.reason
          : new BytechefAppError('ABORTED', 'The ByteChef call was aborted', {cause: signal.reason});
  }

  function untilAborted<T>(promise: Promise<T>, signal: AbortSignal): Promise<T> {
      if (signal.aborted) {
          return Promise.reject(abortError(signal));
      }

      return new Promise<T>((resolve, reject) => {
          const onAbort = () => reject(abortError(signal));

          signal.addEventListener('abort', onAbort, {once: true});

          promise.then(
              (value) => {
                  signal.removeEventListener('abort', onAbort);
                  resolve(value);
              },
              (error: unknown) => {
                  signal.removeEventListener('abort', onAbort);
                  reject(error);
              }
          );
      });
  }

  function parseErrorBody(text: string): ErrorBody | undefined {
      if (!text) {
          return undefined;
      }

      try {
          const parsed: unknown = JSON.parse(text);

          return typeof parsed === 'object' && parsed !== null ? (parsed as ErrorBody) : undefined;
      } catch {
          return undefined;
      }
  }

  export function createRequester(getConfig: () => ResolvedConfig): Requester {
      return async <T>({body, method, path, signal}: RequestOptions): Promise<RequestResult<T>> => {
          if (signal?.aborted) {
              throw new BytechefAppError('ABORTED', 'The ByteChef call was aborted', {cause: signal.reason});
          }

          const config = getConfig();
          const controller = new AbortController();
          const timeout = setTimeout(
              () => controller.abort(new BytechefAppError('TIMEOUT', `ByteChef did not answer within ${config.timeoutMs} ms`)),
              config.timeoutMs
          );
          const onAbort = () => controller.abort(new BytechefAppError('ABORTED', 'The ByteChef call was aborted'));

          signal?.addEventListener('abort', onAbort, {once: true});

          const headers: Record<string, string> = {
              accept: 'application/json',
              authorization: `Bearer ${config.appKey}`,
          };

          if (body !== undefined) {
              headers['content-type'] = 'application/json';
          }

          try {
              let response: Response;

              try {
                  response = await config.fetch(joinUrl(config.baseUrl, `${API_PREFIX}${path}`), {
                      body: body === undefined ? undefined : JSON.stringify(body),
                      headers,
                      method,
                      signal: controller.signal,
                  });
              } catch (error) {
                  if (controller.signal.aborted) {
                      throw abortError(controller.signal);
                  }

                  throw new BytechefAppError('NETWORK_ERROR', `ByteChef could not be reached: ${(error as Error).message}`, {
                      cause: error,
                  });
              }

              let text: string;

              try {
                  text = await untilAborted(response.text(), controller.signal);
              } catch (error) {
                  if (error instanceof BytechefAppError) {
                      throw error;
                  }

                  if (response.ok) {
                      throw new BytechefAppError('NETWORK_ERROR', `Reading the ByteChef answer failed: ${(error as Error).message}`, {
                          cause: error,
                          status: response.status,
                      });
                  }

                  text = '';
              }

              if (!response.ok) {
                  const errorBody = parseErrorBody(text);
                  const code = typeof errorBody?.code === 'string' ? errorBody.code : 'HTTP_ERROR';
                  const message = typeof errorBody?.message === 'string' ? errorBody.message : `ByteChef answered ${response.status}`;

                  throw new BytechefAppError(code, message, {status: response.status});
              }

              if (text === '') {
                  return {data: undefined as T, status: response.status};
              }

              try {
                  return {data: JSON.parse(text) as T, status: response.status};
              } catch (error) {
                  throw new BytechefAppError(
                      'INVALID_RESPONSE',
                      `ByteChef answered ${response.status} with a body that is not JSON; check that BYTECHEF_URL points at the ByteChef server`,
                      {cause: error, status: response.status}
                  );
              }
          } finally {
              clearTimeout(timeout);
              signal?.removeEventListener('abort', onAbort);
          }
      };
  }
  ```

  ```ts
  import type {CallOptions} from './connections';
  import {BytechefAppError} from './errors';
  import type {Requester} from './request';
  import type {AppTool, JsonSchema} from './types';

  export const TOOL_LISTING_TTL_MS = 60_000;

  type RawTool = components['schemas']['AppTool'];

  const ANY_OBJECT: JsonSchema = {additionalProperties: true, type: 'object'};

  function parseParameters(parameters: string): JsonSchema {
      try {
          const parsed: unknown = JSON.parse(parameters);

          return typeof parsed === 'object' && parsed !== null && !Array.isArray(parsed) ? (parsed as JsonSchema) : {...ANY_OBJECT};
      } catch {
          return {...ANY_OBJECT};
      }
  }

  export function createToolsApi(request: Requester, now: () => number = () => Date.now()) {
      let cache: {fetchedAt: number; tools: AppTool[]} | undefined;

      async function fetchListing(signal?: AbortSignal): Promise<AppTool[]> {
          const {data} = await request<RawTool[]>({method: 'GET', path: '/tools', signal});

          const tools = data.map((tool) => ({...tool, parameters: parseParameters(tool.parameters)}));

          cache = {fetchedAt: now(), tools};

          return tools;
      }

      async function cachedListing(signal?: AbortSignal): Promise<AppTool[]> {
          if (cache && now() - cache.fetchedAt < TOOL_LISTING_TTL_MS) {
              return cache.tools;
          }

          return fetchListing(signal);
      }

      async function execute<T = unknown>(bindingKey: string, toolName: string, input: Record<string, unknown>, options: CallOptions = {}): Promise<T> {
          const {data} = await request<{result: T}>({
              body: {input},
              method: 'POST',
              path: `/connections/${encodeURIComponent(bindingKey)}/tools/${encodeURIComponent(toolName)}`,
              signal: options.signal,
          });

          return data.result;
      }

      return {
          execute,

          async executeByName<T = unknown>(flatName: string, input: Record<string, unknown>, options: CallOptions = {}): Promise<T> {
              let tool = (await cachedListing(options.signal)).find((candidate) => candidate.name === flatName);

              if (!tool) {
                  tool = (await fetchListing(options.signal)).find((candidate) => candidate.name === flatName);
              }

              if (!tool) {
                  throw new BytechefAppError('APP_TOOL_NOT_FOUND', `No tool named '${flatName}' is allowed for this app`);
              }

              return execute<T>(tool.bindingKey, tool.toolName, input, options);
          },

          list(options: CallOptions = {}): Promise<AppTool[]> {
              return fetchListing(options.signal);
          },
      };
  }
  ```

  ```ts
  import type {components} from '../generated/openapi';
  import type {CallOptions} from './connections';
  import type {Requester} from './request';
  import type {ProxyBody, ProxyRequest, ProxyResult} from './types';

  type RawProxyResponse = components['schemas']['ProxyResponse'];

  function bytesToBase64(bytes: Uint8Array): string {
      let binary = '';

      for (let index = 0; index < bytes.length; index += 0x8000) {
          binary += String.fromCharCode(...bytes.subarray(index, index + 0x8000));
      }

      return btoa(binary);
  }

  function base64ToBytes(base64: string): Uint8Array {
      const binary = atob(base64);
      const bytes = new Uint8Array(binary.length);

      for (let index = 0; index < binary.length; index += 1) {
          bytes[index] = binary.charCodeAt(index);
      }

      return bytes;
  }

  export function encodeProxyBody(body: ProxyBody | undefined, contentType: string | undefined): {body?: string; bodyEncoding?: 'BASE64' | 'UTF8'; contentType?: string} {
      if (body === undefined) {
          return contentType === undefined ? {} : {contentType};
      }

      if (typeof body === 'string') {
          return contentType === undefined ? {body, bodyEncoding: 'UTF8'} : {body, bodyEncoding: 'UTF8', contentType};
      }

      if (body instanceof Uint8Array) {
          return {body: bytesToBase64(body), bodyEncoding: 'BASE64', contentType: contentType ?? 'application/octet-stream'};
      }

      return {body: JSON.stringify(body), bodyEncoding: 'UTF8', contentType: contentType ?? 'application/json'};
  }

  function toResult(raw: RawProxyResponse): ProxyResult {
      const bytes = raw.body === null || raw.body === undefined ? new Uint8Array() : raw.bodyEncoding === 'BASE64' ? base64ToBytes(raw.body) : new TextEncoder().encode(raw.body);
      const text = raw.body === null || raw.body === undefined ? '' : raw.bodyEncoding === 'BASE64' ? new TextDecoder().decode(bytes) : raw.body;

      return {
          body: raw.body ?? null,
          bodyEncoding: raw.bodyEncoding,
          bytes: () => bytes,
          headers: Object.fromEntries(Object.entries(raw.headers ?? {}).map(([name, values]) => [name, [...values]])),
          json: <T = unknown>(): T => JSON.parse(text) as T,
          status: raw.status,
          text: () => text,
      };
  }

  export function createProxyApi(request: Requester) {
      return async (bindingKey: string, proxyRequest: ProxyRequest, options: CallOptions = {}): Promise<ProxyResult> => {
          const {body, contentType, ...rest} = proxyRequest;

          const {data} = await request<RawProxyResponse>({
              body: {...rest, ...encodeProxyBody(body, contentType)},
              method: 'POST',
              path: `/connections/${encodeURIComponent(bindingKey)}/proxy`,
              signal: options.signal,
          });

          return toResult(data);
      };
  }
  ```

  ```ts
  import type {CallOptions} from './connections';
  import {BytechefAppError} from './errors';
  import type {Requester} from './request';
  import type {AppWorkflow, WorkflowRun, WorkflowRunStatus} from './types';

  export type WaitMode = false | true | 'approval';

  export interface ExecuteWorkflowOptions extends CallOptions {
      pollDelaysMs?: number[];
      wait?: WaitMode;
      waitSeconds?: number;
  }

  export const DEFAULT_POLL_DELAYS_MS = [1_000, 2_000, 3_000, 4_000, 5_000];

  export interface WorkflowsApi {
      execute(workflowKey: string, input: Record<string, unknown>, options?: ExecuteWorkflowOptions): Promise<WorkflowRun>;
      getRun(runId: string, options?: CallOptions): Promise<WorkflowRun>;
      list(options?: CallOptions): Promise<AppWorkflow[]>;
  }

  export function isFinished(status: WorkflowRunStatus): boolean {
      return status === 'COMPLETED' || status === 'FAILED' || status === 'CANCELLED';
  }

  function defaultSleep(ms: number, signal?: AbortSignal): Promise<void> {
      return new Promise((resolve, reject) => {
          if (signal?.aborted) {
              reject(signal.reason);

              return;
          }

          const timer = setTimeout(() => {
              signal?.removeEventListener('abort', onAbort);
              resolve();
          }, ms);

          function onAbort() {
              clearTimeout(timer);
              reject(signal!.reason);
          }

          signal?.addEventListener('abort', onAbort, {once: true});
      });
  }

  function shouldKeepWaiting(run: WorkflowRun, wait: WaitMode): boolean {
      if (wait === false || isFinished(run.status)) {
          return false;
      }

      return run.status !== 'APPROVAL_REQUIRED' || wait === 'approval';
  }

  export function createWorkflowsApi(request: Requester, sleep: (ms: number, signal?: AbortSignal) => Promise<void> = defaultSleep): WorkflowsApi {
      async function getRun(runId: string, options: CallOptions = {}): Promise<WorkflowRun> {
          const {data} = await request<WorkflowRun>({method: 'GET', path: `/workflow-runs/${encodeURIComponent(runId)}`, signal: options.signal});

          return data;
      }

      return {
          async execute(workflowKey, input, options = {}) {
              const body: Record<string, unknown> = {input};

              if (options.waitSeconds !== undefined) {
                  body['waitSeconds'] = options.waitSeconds;
              }

              const {data} = await request<WorkflowRun>({body, method: 'POST', path: `/workflows/${encodeURIComponent(workflowKey)}`, signal: options.signal});

              let run = data;
              const delays = options.pollDelaysMs ?? DEFAULT_POLL_DELAYS_MS;
              let attempt = 0;

              while (shouldKeepWaiting(run, options.wait ?? false)) {
                  const delay = delays[Math.min(attempt, delays.length - 1)] ?? 0;

                  attempt += 1;

                  try {
                      await sleep(delay, options.signal);

                      run = await getRun(run.runId, options);
                  } catch (error) {
                      if (error instanceof BytechefAppError && error.code === 'ABORTED') {
                          throw new BytechefAppError('ABORTED', `Stopped waiting for workflow run ${run.runId}`, {cause: error, runId: run.runId});
                      }

                      if (options.signal?.aborted) {
                          throw new BytechefAppError('ABORTED', `Stopped waiting for workflow run ${run.runId}`, {cause: error, runId: run.runId});
                      }

                      throw error;
                  }
              }

              return run;
          },

          getRun,

          async list(options = {}) {
              const {data} = await request<AppWorkflow[]>({method: 'GET', path: '/workflows', signal: options.signal});

              return data;
          },
      };
  }
  ```

  ```ts
  function asRecord(value: unknown, name: string): Record<string, unknown> {
      if (typeof value !== 'object' || value === null || Array.isArray(value)) {
          throw new TypeError(`${name} must be an object`);
      }

      return value as Record<string, unknown>;
  }

  function requireString(record: Record<string, unknown>, name: string): string {
      const value = record[name];

      if (typeof value !== 'string' || value === '') {
          throw new TypeError(`${name} must be a non-empty string`);
      }

      return value;
  }

  function optionalString(record: Record<string, unknown>, name: string): string | undefined {
      const value = record[name];

      if (value === undefined || value === null) {
          return undefined;
      }

      if (typeof value !== 'string') {
          throw new TypeError(`${name} must be a string`);
      }

      return value;
  }

  function optionalNonNegativeInteger(record: Record<string, unknown>, name: string): number | undefined {
      const value = record[name];

      if (value === undefined || value === null) {
          return undefined;
      }

      if (typeof value !== 'number' || !Number.isInteger(value) || value < 0) {
          throw new TypeError(`${name} must be a non-negative integer`);
      }

      return value;
  }

  function optionalStringListMap(record: Record<string, unknown>, name: string): Record<string, string[]> | undefined {
      const value = record[name];

      if (value === undefined || value === null) {
          return undefined;
      }

      const map = asRecord(value, name);
      const result: Record<string, string[]> = {};

      for (const [key, entry] of Object.entries(map)) {
          if (!Array.isArray(entry) || entry.some((item) => typeof item !== 'string')) {
              throw new TypeError(`${name}.${key} must be an array of strings`);
          }

          result[key] = entry as string[];
      }

      return result;
  }

  export function executeActionInput(input: unknown): ExecuteActionInput {
      const record = asRecord(input, 'input');
      const componentVersion = optionalNonNegativeInteger(record, 'componentVersion');

      return {
          actionName: requireString(record, 'actionName'),
          bindingKey: requireString(record, 'bindingKey'),
          ...(componentVersion === undefined ? {} : {componentVersion}),
          input: asRecord(record['input'], 'input.input'),
      };
  }

      const record = asRecord(input, 'input');

      return {
          bindingKey: requireString(record, 'bindingKey'),
          input: asRecord(record['input'], 'input.input'),
          toolName: requireString(record, 'toolName'),
      };
  }

      const record = asRecord(input, 'input');

      return {
          input: asRecord(record['input'], 'input.input'),
          name: requireString(record, 'name'),
      };
  }

  export function proxyInput(input: unknown): ProxyInput {
      const record = asRecord(input, 'input');
      const request = asRecord(record['request'], 'request');
      const method = requireString(request, 'method');

      if (!PROXY_METHODS.includes(method as ProxyMethod)) {
          throw new TypeError(`request.method must be one of ${PROXY_METHODS.join(', ')}`);
      }

      const path = requireString(request, 'path');

      if (!path.startsWith('/')) {
          throw new TypeError('request.path must start with /');
      }

      const body = request['body'];

      if (body !== undefined && body !== null && typeof body !== 'string' && (typeof body !== 'object' || body instanceof Uint8Array)) {
          throw new TypeError('request.body must be a string, an object or an array');
      }

      const contentType = optionalString(request, 'contentType');
      const headers = optionalStringListMap(request, 'headers');
      const query = optionalStringListMap(request, 'query');

      return {
          bindingKey: requireString(record, 'bindingKey'),
          request: {
              ...(body === undefined || body === null ? {} : {body: body as ProxyRequest['body']}),
              ...(contentType === undefined ? {} : {contentType}),
              ...(headers === undefined ? {} : {headers}),
              method: method as ProxyMethod,
              path,
              ...(query === undefined ? {} : {query}),
          },
      };
  }

  export function executeWorkflowInput(input: unknown): ExecuteWorkflowInput {
      const record = asRecord(input, 'input');
      const wait = record['wait'];

      if (wait !== undefined && wait !== true && wait !== false && wait !== 'approval') {
          throw new TypeError("wait must be true, false or 'approval'");
      }

      const waitSeconds = optionalNonNegativeInteger(record, 'waitSeconds');

      return {
          input: asRecord(record['input'], 'input.input'),
          ...(wait === undefined ? {} : {wait}),
          ...(waitSeconds === undefined ? {} : {waitSeconds}),
          workflowKey: requireString(record, 'workflowKey'),
      };
  }

  export function getWorkflowRunInput(input: unknown): GetWorkflowRunInput {
      return {runId: requireString(asRecord(input, 'input'), 'runId')};
  }
  ```

  ```ts
  import {BytechefAppError, type BytechefClient, type JsonSchema, type WaitMode, type WorkflowRun} from '../index';
  import {toFlatKey} from './names';

  export interface ToAiSdkToolsOptions {
      include?: string[];
      waitForWorkflows?: WaitMode;
      workflows?: boolean;
  }

  const ANY_OBJECT: JsonSchema = {additionalProperties: true, type: 'object'};

  const APPROVAL_REQUIRED = 'Approval required: a person must decide before the workflow continues';

  export function describeRun(run: WorkflowRun): unknown {
      switch (run.status) {
          case 'COMPLETED':
              return run.result ?? null;
          case 'APPROVAL_REQUIRED':
              return run.approvalFormUrl ? `${APPROVAL_REQUIRED}. Decide at ${run.approvalFormUrl}` : APPROVAL_REQUIRED;
          case 'FAILED':
              return `Workflow failed: ${run.error?.message ?? 'no details'}`;
          case 'CANCELLED':
              return 'Workflow was cancelled';
          default:
              return `Workflow is still running (run ${run.runId})`;
      }
  }

  async function guarded<T>(call: () => Promise<T>): Promise<T | string> {
      try {
          return await call();
      } catch (error) {
          if (error instanceof BytechefAppError && error.code !== 'ABORTED') {
              return `Error ${error.code}: ${error.message}`;
          }

          throw error;
      }
  }

  function included(include: string[] | undefined, ...candidates: string[]): boolean {
      return include === undefined || candidates.some((candidate) => include.includes(candidate));
  }

  export async function toAiSdkTools(bytechef: BytechefClient, options: ToAiSdkToolsOptions = {}): Promise<ToolSet> {
      const tools: ToolSet = {};

      for (const tool of await bytechef.tools.list()) {
          if (!included(options.include, tool.name, tool.bindingKey)) {
              continue;
          }

          tools[tool.name] = dynamicTool({
              description: tool.description ?? `${tool.toolName} on ${tool.componentName}`,
              execute: (input, {abortSignal}) =>
                  guarded(() => bytechef.tools.executeByName(tool.name, input as Record<string, unknown>, {signal: abortSignal})),
              inputSchema: jsonSchema(tool.parameters as JSONSchema7),
          });
      }

      if (options.workflows) {
          for (const workflow of await bytechef.workflows.list()) {
              const name = toFlatKey(workflow.workflowKey);

              if (!workflow.available || !included(options.include, name, workflow.workflowKey)) {
                  continue;
              }

              tools[name] = dynamicTool({
                  description: workflow.description ?? workflow.name,
                  execute: (input, {abortSignal}) =>
                      guarded(async () =>
                          describeRun(
                              await bytechef.workflows.execute(workflow.workflowKey, input as Record<string, unknown>, {
                                  signal: abortSignal,
                                  wait: options.waitForWorkflows ?? true,
                              })
                          )
                      ),
                  inputSchema: jsonSchema((workflow.inputSchema ?? ANY_OBJECT) as JSONSchema7),
              });
          }
  ```

  ```js
  import {readdirSync, readFileSync, statSync} from 'node:fs';
  import {join} from 'node:path';

  const CANARY_KEY = process.env.BYTECHEF_APP_KEY ?? '';
  const CLIENT_DIRS = ['dist/client', '.output/public'];
  const FORBIDDEN = ['BYTECHEF_APP_KEY', '/api/app/v1'];
  const RPC_MARKER = '_serverFn';

  function walk(dir) {
      return readdirSync(dir).flatMap((name) => {
          const path = join(dir, name);

          return statSync(path).isDirectory() ? walk(path) : [path];
      });
  }

  function isDirectory(dir) {
      try {
          return statSync(dir).isDirectory();
      } catch {
          return false;
      }
  }

  const clientDir = CLIENT_DIRS.find(isDirectory);

  if (!clientDir) {
      console.error(`No client build found in ${CLIENT_DIRS.join(' or ')}`);
      process.exit(1);
  }

  const files = walk(clientDir).filter((file) => /\.(js|mjs|html|css|json)$/.test(file));
  const problems = [];
  let rpcFiles = 0;

  for (const file of files) {
      const text = readFileSync(file, 'utf8');

      for (const forbidden of FORBIDDEN) {
          if (text.includes(forbidden)) {
              problems.push(`${file}: contains ${forbidden}`);
          }
      }

      if (CANARY_KEY && text.includes(CANARY_KEY)) {
          problems.push(`${file}: contains the app key value`);
      }

      if (text.includes(RPC_MARKER)) {
          rpcFiles += 1;
      }
  }

  if (rpcFiles === 0) {
      problems.push(`no client file contains ${RPC_MARKER}: the server functions were not compiled into RPC stubs`);
  }

  if (problems.length > 0) {
      console.error(problems.join('\n'));
      process.exit(1);
  }

  console.log(`Checked ${files.length} client files under ${clientDir}: RPC stubs in ${rpcFiles}, nothing server-only`);
  ```
